## 问题一：急性胰腺炎的发病机制是？

急性胰腺炎（acute pancreatitis, AP）的本质是**胰酶在腺泡细胞内提前激活导致的胰腺自身消化，并由此触发局部及全身炎症级联反应**。可分为四个递进层次。

### 1. 病因触发

| 病因 | 备注 |
|---|---|
| 胆石症（胆源性） | 我国及全球最常见病因，结石或微结石嵌顿于壶腹部 |
| 酒精 | 第二位常见，多在长期饮酒基础上急性发作 |
| 高甘油三酯血症 | TG > 11.3 mmol/L（1000 mg/dL）风险显著升高，我国占比逐年上升 |
| ERCP 术后 | 医源性，占 3%–10% |
| 药物 | 硫唑嘌呤、丙戊酸、GLP-1 类似物等 |
| 高钙血症 | 甲旁亢等 |
| 遗传 | *PRSS1*（阳离子胰蛋白酶原）、*SPINK1*、*CFTR*、*CTRC* 突变 |
| 其他 | 外伤、自身免疫性胰腺炎、胰腺分裂、肿瘤梗阻、感染、特发性 |

### 2. 起始事件：腺泡细胞内胰蛋白酶原提前激活

这是所有病因汇聚的共同通路：

- **病理性钙信号**——胆汁酸、脂肪酸乙酯（酒精代谢产物）等经 IP₃R/RyR 通道引起内质网 Ca²⁺ 持续释放，并通过 store-operated Ca²⁺ entry 持续内流，形成**胞质 Ca²⁺ 持续性升高**（区别于生理性钙振荡）。
- **线粒体功能障碍**——线粒体钙超载导致线粒体通透性转换孔（mPTP）开放、膜电位崩解、ATP 耗竭。ATP 是维持腺泡细胞存活和正常分泌的前提，其耗竭直接决定细胞走向**坏死**而非凋亡。
- **酶原异常激活**——分泌受阻使酶原颗粒与溶酶体共定位（colocalization），溶酶体内**组织蛋白酶 B（cathepsin B）**切割胰蛋白酶原生成活性胰蛋白酶，进而级联激活糜蛋白酶原、弹性蛋白酶原、磷脂酶 A₂ 等，形成**胰腺自身消化**。
- **细胞稳态崩坏**——自噬流受损、溶酶体膜不稳定、内质网应激与未折叠蛋白反应（UPR），共同放大上述损伤。

### 3. 局部炎症放大

值得强调：**炎症通路与胰蛋白酶激活是平行的两条线，并非单纯下游事件**。

- 腺泡细胞内 **NF-κB** 早期活化，独立于胰蛋白酶，释放 TNF-α、IL-1β、IL-6、IL-8 及趋化因子；
- 中性粒细胞与巨噬细胞浸润，中性粒细胞胞外诱捕网（NETs）加重导管堵塞与组织损伤；
- 坏死细胞释放 DAMPs（HMGB1、线粒体 DNA、ATP）经 TLR/NLRP3 炎症小体进一步放大；
- 微循环障碍、血管通透性增加、缺血再灌注损伤 → 由**水肿型**进展为**坏死型**。

### 4. 全身放大与双相病程

- **早期（起病 1–2 周）**：以 **SIRS** 为主导，毛细血管渗漏 + 第三间隙丢失 → 有效循环血量骤降 → 器官低灌注 → **MODS**（以 ARDS、AKI 最常见）。此期死亡多源于持续性器官衰竭。
- **后期（> 2 周）**：肠黏膜屏障受损、肠道菌群移位 → **感染性胰腺坏死**及脓毒症。此期死亡多源于感染并发症。

> 这条"双相死亡曲线"是理解现代治疗策略（早期支持、后期延迟干预）的关键。

### 5. 分类与严重度（修订版 Atlanta 分类，2012）

**病理类型**：间质水肿性胰腺炎 / 坏死性胰腺炎

**局部并发症**：
- 急性胰周液体积聚（APFC，< 4 周，无坏死）
- 胰腺假性囊肿（> 4 周，无坏死）
- 急性坏死物积聚（ANC，< 4 周，含坏死）
- 包裹性坏死（WON，> 4 周，含坏死）

**严重度**：
| 分级 | 定义 |
|---|---|
| 轻症（MAP） | 无器官衰竭，无局部/全身并发症 |
| 中重症（MSAP） | 一过性器官衰竭（< 48 h）和/或局部、全身并发症 |
| 重症（SAP） | **持续性**器官衰竭（> 48 h），改良 Marshall 评分 ≥ 2 分 |

## 问题二：目前主流治疗方式？

现代 AP 治疗的核心理念可概括为：**没有特效药，胜负取决于液体、营养、病因和干预时机四件事做得对不对。**

### 1. 诊断（三选二）

① 特征性上腹痛（持续、向背部放射）；② 血淀粉酶或脂肪酶 > 3 倍正常上限（脂肪酶特异性更佳）；③ 影像学（增强 CT / MRI / 超声）符合。

> 增强 CT 评估坏死范围建议在**发病 72–96 小时后**进行，过早会低估坏死。

### 2. 早期液体治疗——观念已经反转

过去"积极大量补液"的教条已被推翻。**WATERFALL 试验（NEJM, 2022）**比较积极补液（20 mL/kg 冲击 + 3 mL/kg/h）与适度补液（1.5 mL/kg/h，仅低血容量者给 10 mL/kg 冲击），结果：积极组**液体过负荷显著增多，重症发生率并无降低**，试验因安全性提前终止。

当前主流做法：
- 首选**乳酸林格液**（较生理盐水更少诱发 SIRS、避免高氯性酸中毒；高钙血症者除外）；
- **目标导向、适度补液**，以尿量、心率、血压、BUN 下降、血细胞比容趋势动态调整；
- 前 24–48 小时密切复评，警惕肺水肿与腹腔间隔室综合征（ACS）。

### 3. 镇痛

充分镇痛属于基础治疗。**不再回避阿片类药物**——"吗啡收缩 Oddi 括约肌加重病情"缺乏临床证据支持。可选用氢吗啡酮、芬太尼等，或联合 NSAIDs（注意肾功能）。

### 4. 早期肠内营养（重要转变）

- **不再常规禁食**。轻症患者若无恶心呕吐、腹痛可耐受，应在 **24 小时内尽早经口进食低脂软食**，早期进食可缩短住院时间；
- 重症或不能耐受经口进食者，**48–72 小时内启动肠内营养**（鼻胃管与鼻空肠管疗效相当，鼻胃管更简便）；
- **PYTHON 试验（NEJM, 2014）**显示：早期鼻肠管喂养并不优于 72 小时后按需经口进食，故**优先尝试经口**；
- **全肠外营养仅作为肠内营养失败或禁忌时的补充**，因其增加感染与导管相关并发症。

### 5. 病因治疗（真正改变结局的一环）

| 病因 | 处理 |
|---|---|
| 胆源性 + 急性胆管炎 | **急诊 ERCP + 括约肌切开（< 24 h）** |
| 胆源性、无胆管炎、无梗阻 | **不推荐**常规早期 ERCP（APEC 试验阴性） |
| 轻症胆源性 | **同次住院期间行胆囊切除术**（PONCHO 试验：显著降低复发与再入院） |
| 重症/坏死性胆源性 | 胆囊切除延迟至炎症消退、积液吸收或包裹后 |
| 高甘油三酯血症 | 禁食、胰岛素（±肝素争议）、控制血糖；血浆置换在近期 RCT 中未显示明确获益，不作常规推荐；恢复期贝特类 + 饮食控制 |
| 酒精性 | 住院期间即开始戒酒干预，可降低复发率 |
| 药物性 | 停用可疑药物 |

### 6. 抗生素

**不推荐预防性使用抗生素**（包括重症与坏死性胰腺炎）——多项 RCT 与荟萃分析均未显示降低病死率，反而增加耐药与真菌感染。

仅在以下情况使用：确诊或高度怀疑**感染性坏死**（临床恶化 + 影像见坏死内气泡 + 感染指标升高）、胆管炎、或明确的胰外感染。首选可穿透胰腺组织的碳青霉烯类、喹诺酮类 + 甲硝唑等。

### 7. 坏死性胰腺炎的干预——延迟 + 升阶梯

这是近十余年最重要的进步，**早期开腹坏死组织清除术已被淘汰**（病死率极高）。

- **延迟**：尽可能推迟至发病 **4 周后**，待坏死充分包裹（WON）；
- **升阶梯（step-up approach）**：
  1. 经皮穿刺置管引流（PCD）或内镜下经胃/十二指肠引流（LAMS 支架）；
  2. 无效再行微创坏死组织清除——视频辅助腹膜后清创（VARD）或内镜下清创；
  3. 开腹手术作为最后手段。
- 证据：**PANTER 试验（NEJM, 2010）**证实升阶梯优于开腹；**TENSION 试验（Lancet, 2018）**显示内镜升阶梯较外科升阶梯**显著减少胰瘘和住院时间**。
- 无菌性坏死若无症状，**不需要干预**。

### 8. 重症支持治疗

器官功能支持（机械通气、CRRT、血管活性药）、腹内压监测与 ACS 处理、血糖管理、DVT 预防、必要时 ICU 转入。

### 9. 药物治疗的现状与争议（含乌司他丁）

| 药物 | 机制 | 循证与指南地位 |
|---|---|---|
| **乌司他丁（UTI）** | 人尿提取的糖蛋白，**广谱蛋白酶抑制剂**（抑制胰蛋白酶、糜蛋白酶、弹性蛋白酶、透明质酸酶等），稳定溶酶体膜，抑制炎症介质释放 | **中国、日本指南推荐**用于中重症/重症 AP；ACG、AGA、IAP/APA 等**国际指南未推荐**，理由是缺乏大样本高质量 RCT。属地区实践差异 |
| 加贝酯 / 萘莫司他 | 合成蛋白酶抑制剂 | 同上，日本推荐动脉持续灌注给药，国际证据不足 |
| 生长抑素 / 奥曲肽 | 抑制胰腺外分泌 | 我国常用；国际荟萃分析未证实降低病死率 |
| NSAIDs（吲哚美辛栓） | 抑制磷脂酶 A₂ 与炎症 | **仅在 ERCP 术后胰腺炎预防中证据充分**（直肠给药，一线推荐），非治疗用药 |
| 中药（大黄、清胰汤） | 促进胃肠动力、通腑 | 中国指南可选，国际无 |

> **一句话总结**：抑酶类药物（含乌司他丁）在东亚是常规、在欧美不被推荐，二者的分歧不在于机制是否合理，而在于**是否有足以改变硬终点（病死率、器官衰竭）的高质量 RCT 证据**。这也正是该方向后续研究的价值所在。
