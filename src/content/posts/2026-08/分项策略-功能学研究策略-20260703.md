本文整理自一份覆盖重组酶类、糖蛋白激素及单抗/双抗三大产品线的功能学研究分项策略，系统梳理从早研候选分子筛选、IND申报、临床期间管理、PPQ工艺验证直至BLA申报的全生命周期效价检测规划。文章依次介绍策略定位与分类体系、法规依据、功能学方法学体系、各阶段研究要求及特殊考量，并在附录中给出各产品线按注册阶段展开的功能学检测矩阵。

## 策略定位与分类体系

### 目的与核心定位

功能学研究是生物制品质量研究的核心组成部分，通过对产品生物学活性的定量测定，直接反映产品的安全性与有效性。ICH Q6B明确要求将效价（potency）作为生物技术产品规格体系的核心要素，效价检测通过生物活性测定（bioassay）定量产品的功能属性，与蛋白质含量测定（protein mass）相互补充，共同构成产品质量的完整表征。

本策略覆盖生物制品从早研候选分子筛选至IND申报、临床期间管理、PPQ工艺验证直至BLA申报的全生命周期功能学研究规划，明确各阶段应执行的功能学测定项目、方法学验证要求和批次要求，确保功能学数据的完整性、合规性与可追溯性。策略设计以ICH Q6B、ICH Q2(R2)、ICH Q5C、ICH Q5E及国内外主要监管机构的技术要求为依据，支持关键质量属性（CQA）清单的建立与产品质量标准的制定。

### 适用范围与产品线

本策略适用于三大类重组生物制品的功能学研究规划，涵盖原液（Drug Substance, DS）和制剂（Drug Product, DP）两个层面：

| 产品分类 | 代表产品 | 表达系统 | 主要功能学测定类型 |
|---------|---------|---------|----------------|
| **酶类产品** | | | |
| ├─ 重组透明质酸酶 | CHO | 酶活性测定（浊度法/比色法） |
| ├─ 糜蛋白酶 | 酵母（Pichia） | 酶活性测定（色原底物法） |
| ├─ IgG降解酶（如IdeS） | 大肠杆菌（E. coli） | IgG裂解活性测定 |
| └─ 重组乌司他丁（酶抑制剂）| CHO | 胰蛋白酶抑制活性（Kunitz法） |
| **糖蛋白激素** | | | |
| ├─ 卵泡刺激素（FSH-CTP） | CHO | 受体介导细胞效价（cAMP/报告基因） |
| ├─ 重组绒促性激素（hCG） | CHO | 受体介导细胞效价（cAMP/报告基因） |
| └─ 重组促红细胞生成素（EPO） | CHO | 细胞增殖效价（TF-1细胞法） |
| **单克隆抗体/双特异性抗体** | | | |
| ├─ 单抗（SC皮下注射） | CHO | 靶点结合（ELISA/BLI/SPR）+ 细胞效价 + Fc效应功能 |
| └─ 双特异性抗体 | CHO | 双靶点结合 + 双功能细胞效价 + Fc效应功能 |

### 三大功能学类别

| 类别 | 内容 | 适用产品 |
|------|------|---------|
| **I类：效价/生物活性测定** | 酶活性、酶抑制活性、受体介导细胞效价、抗体细胞效价 | 全部产品 |
| **II类：靶点结合活性测定** | ELISA结合、SPR动力学、BLI亲和力 | 单抗、双抗 |
| **III类：Fc效应功能测定** | ADCC、CDC、ADCP、FcγR/FcRn结合 | 单抗、双抗（Fc效应机制相关） |

### 核心原则

- **以作用机制（MoC）为导向**：功能学测定方法的选择必须基于产品的已知作用机制（Mechanism of Action），覆盖临床药效的关键生物学途径。单一功能学测定方法通常不足以覆盖多机制产品的全部生物活性。
- **递进式验证深度**：早研阶段以快速适用性评估为主，IND阶段完成方法确认（Method Qualification），BLA阶段完成基于ICH Q2(R2)的完整分析方法验证（Full Validation）；全程保持方法的延续性。
- **效价单位可追溯**：效价结果应以经国际参考标准品（WHO IRP）或国家标准品溯源的参考对照品校准，确保批次间和产品生命周期内的效价单位一致性（参见模板5·对照品策略）。
- **药典方法与替代方法协调**：对有国际/国内药典方法的产品（EPO、FSH、hCG、透明质酸酶），优先评估药典方法的适用性，在充分验证的基础上可采用体外替代方法，须提供相关性证明数据。
- **功能学数据贯穿全生命周期**：效价测定是稳定性研究（ICH Q5C）、工艺变更可比性评估（ICH Q5E）和生物类似药相似性评估的必要指标，不可省略。

## 法规依据与指导原则

### ICH指南

- **ICH Q6B**（Step 4: 1999年3月10日）：将效价（potency）列为生物制品规格的核心要素，要求通过bioassay定量生物活性；明确效价须以国际/国家参考标准溯源的活性单位表示，区别于蛋白含量测定；是功能学测定项目设计和验收标准制定的直接法规依据。
- **ICH Q2(R2)**（Step 4: 2023年11月1日；FDA/EMA实施: 2024年6月14日）：相比R1版本，R2版本明确将bioassay（生物活性测定）纳入分析方法验证适用范围；规定细胞法效价检测的精密度可接受CV通常≤20%，准确度回收率80–120%；与ICH Q14配套引入全生命周期验证理念；是IND方法确认和BLA完整验证的直接框架依据。
- **ICH Q5C**（Step 4: 1995年11月30日）：将生物活性测定（biological activity assay）列为**必须**纳入关键稳定性研究的项目，作为核心稳定性指示参数（stability-indicating parameter）；效价方法须对热降解、氧化、聚集、脱酰胺等降解途径敏感，能反映产品真实活性丧失。
- **ICH Q5E**（Step 4: 2004年11月18日）：要求工艺变更前后开展可比性研究，功能学评估（含bioassay、靶点结合、Fc受体结合）是必须评估的维度；对于抗体类产品，糖型改变可影响FcγR结合和ADCC活性，须纳入Fc效应功能评估；明确功能学测定组合须覆盖产品所有已知MoA。
- **ICH Q11**（Step 4: 2012年5月1日）：要求建立药物物质理解，功能学数据（效价、活性）是确立生物活性相关CQA的关键输入，支撑CTD 3.2.S.2节内容。

### FDA与EMA技术要求

**FDA：**

- *Points to Consider in the Manufacture and Testing of Monoclonal Antibody Products for Human Use*（1997年2月，FDA/CBER）：早期mAb效价测定设计的奠基性建议文件，提及效价检测须反映mAb体内预期生物活性，对Fc介导效应功能（ADCC等）的功能学检测必要性作出早期指引。
- *Analytical Procedures and Methods Validation for Drugs and Biologics*（Guidance for Industry，最终版，2015年7月，FDA/CDER & CBER）：明确适用于生物制品效价测定的分析方法验证数据提交要求，要求CMC部分提供效价检测的验证数据以支持对potency的充分证明。
- *Potency Tests for Cellular and Gene Therapy Products*（Guidance for Industry，最终版，2011年1月，FDA/CBER）：为细胞和基因治疗产品效价测定建立建议框架，要求效价检测方法能反映产品体内预期生物功能；监管理念对重组蛋白效价方法的IND/BLA阶段分级要求具有参考价值。
- *Development of Therapeutic Protein Biosimilars: Comparative Analytical Assessment and Other Quality-Related Considerations*（Guidance for Industry，**最终版**，**2025年9月9日**，FDA/CDER & CBER）：现行最新版生物类似药比较分析指南；要求覆盖产品所有已知MoA的功能学比较，包括靶结合、酶活性和其他功能学分析；对抗体类产品，Fc效应功能评估（ADCC、CDC等）是功能学相似性评估的必要组成部分；替代2019年草稿及2015年质量指南。

**EMA：**

- *Guideline on development, production, characterisation and specification for monoclonal antibodies and related products (Rev. 1)*（EMA/CHMP/BWP/532517/2008，生效日期2016年9月1日）：明确要求将potency纳入mAb规格的必须检测项目；对依赖Fc效应功能发挥作用的产品，ADCC和CDC被列为相关功能学检测方法；指出不同适应症中Fc效应功能的重要性存在差异，应基于MoA选择适当的功能学测试组合。
- *Guideline on similar biological medicinal products containing biotechnology-derived proteins as active substance: quality issues (Revision 1)*（EMA/CHMP/BWP/247713/2012，生效日期2014年12月1日）：要求生物类似药规格（原液和制剂）中均须包含效价测定，效价结果应以国际/国家参考标准溯源的活性单位表示；根据产品生物学特性，可采用配体/受体结合法、酶活性测定、细胞法等功能学方法进行比较评估。
- *Guideline on the requirements for quality documentation concerning biological investigational medicinal products in clinical trials (Rev. 2)*（EMA/CHMP/BWP/534898/2008，生效日期2022年1月31日）：规定IND/CTA阶段生物制品所需最低功能学表征数据；IND阶段须提供效价/生物活性测定的初步方法和数据，证明候选药物具有预期生物活性。

### 中国法规与药典要求

- 《人用单克隆抗体质量控制技术指导原则》（2003年3月20日，原SFDA药品审评中心）：要求单克隆抗体产品进行生物活性/效价检测，覆盖与临床适应症相关的功能学测试（含靶点结合）；中国单抗功能学检测要求的基础法规文件。
- 《双特异性抗体抗肿瘤药物临床研发技术指导原则》（NMPA CDE 2022年第40号通告，2022年11月14日）：对双特异性抗体提出双靶点功能学验证要求，须分别验证两个结合域的靶点结合活性及双功能生物学活性（如T细胞重定向杀伤活性）。
- 《治疗用重组蛋白药物首次申报临床试验药学资料撰写指导原则》（2026年4月，NMPA药品审评中心）：明确IND申报中须提供生物活性测定数据，以证明候选产品具有预期功能学特性。
- 《生物类似药研发与评价技术指导原则（试行）》（CFDA 2015年第7号通告，2015年2月28日）：要求候选生物类似药与参照药开展功能学相似性比较，生物活性（效价）是核心比对指标之一。
- 《中国药典》2025年版（三部）相关产品标准：三部收载促红素、促性腺激素等产品的法定质量标准，均规定了生物活性测定方法（效价）作为强制检验项目；具体产品生物活性检测通则和专论须参照ChP 2025年版三部相关章节（**待核实具体章节编号**）。

## 功能学方法学体系

### 酶类产品：酶活性测定

#### 重组透明质酸酶（CHO表达）

透明质酸酶催化底物透明质酸（hyaluronic acid）的水解，导致透明质酸-蛋白质（如血清白蛋白）聚合形成的混浊复合物溶解，混浊度下降程度与酶活性正相关。主要方法包括：

| 方法类型 | 原理 | 优点 | 局限性 |
|---------|------|------|-------|
| 浊度法（Turbidimetric assay） | 测定透明质酸-白蛋白复合物混浊度消解 | 药典通用方法，监管接受度高 | 终点法，灵敏度一般 |
| 比色底物法（p-NP底物）| 人工色原底物水解后释放p-硝基苯酚，405 nm吸收 | 高通量，可动力学法 | 非天然底物，需验证相关性 |
| 荧光底物法（4-MU底物）| 4-甲基伞花基糖苷底物水解释放荧光基团 | 高灵敏度 | 需优化底物浓度 |

关键参数：底物为透明质酸（牛睾丸来源），底物浓度1 mg/mL（浊度法）；pH 5.3–5.5（醋酸盐缓冲液）；温度37°C。效价单位：NF/USP单位（Hymig单位），或定义为消解一定量混浊底物的酶量；以透明质酸酶参考标准品（USP/NF参考标准品或内部参照）校准，以NF单位/mg蛋白质报告。

#### 糜蛋白酶（酵母表达）

糜蛋白酶催化含芳香族/大疏水性氨基酸（Phe、Tyr、Trp、Leu）的肽键水解。采用色原性底物（Suc-Ala-Ala-Pro-Phe-pNA），底物水解释放p-硝基苯胺（pNA），在405 nm处吸收增加，速率与酶活性正相关。关键参数：底物终浓度0.1–1 mM；缓冲液50 mM Tris-HCl, 100 mM NaCl, pH 7.8；温度25°C（动力学读取）；检测波长405 nm；报告参数为初速度（ΔOD/min）与参考标准的相对活性（%）。方法开发阶段建议测定Km和Vmax，了解酵母表达糜蛋白酶的活性特征，与天然来源牛糜蛋白酶进行比较，确认折叠正确性。

#### IgG降解酶（大肠杆菌表达，如IdeS）

IdeS（IgG-degrading enzyme of Streptococcus pyogenes）等IgG裂解酶在铰链区特异性切割IgG重链。活性测定基于对底物IgG的裂解效率，通过SDS-PAGE、CE-SDS或LC-MS定量裂解产物：

| 方法类型 | 原理 | 适用阶段 |
|---------|------|---------|
| 非还原SDS-PAGE法 | 裂解后IgG分子量改变（~150 kDa→~100 kDa + Fc/2），密度扫描计算% | 开发阶段，定性确认 |
| 非还原CE-SDS法 | 高分辨率区分完整IgG与裂解产物，精确定量 | 常规QC检测 |
| LC-MS法 | 肽图确认裂解位点；完整裂解产物质量确认 | 方法开发/特征研究 |

效价表达：以特异活性（Specific Activity，U/mg蛋白质）报告，1 Unit定义为在规定条件下（37°C，30 min）裂解1 μg IgG所需的酶量。

#### 重组乌司他丁（CHO表达，酶抑制剂）

乌司他丁（UTI）为Kunitz型丝氨酸蛋白酶抑制剂，通过直接与胰蛋白酶活性位点结合抑制其活性。效价测定基于对标准胰蛋白酶的抑制活性（胰蛋白酶抑制单位，TIU）。Kunitz法步骤：

1. 将一定量的标准胰蛋白酶与样品或参考品在生理条件下预孵育
2. 加入底物BAEE（N-苯甲酰-L-精氨酸乙酯）或BAPNA（N-α-苯甲酰-DL-精氨酸-4-硝基苯胺）
3. 测定残余胰蛋白酶活性（波长253 nm/405 nm）
4. 样品对胰蛋白酶的抑制程度与参考标准比较

效价单位：TIU/mg蛋白质（1 TIU = 抑制1 μmol/min胰蛋白酶活力所需的抑制剂量）。关键注意：乌司他丁含特殊的O-糖链（硫酸软骨素GAG）修饰，GAG链的完整性可能影响其与胰蛋白酶的结合亲和力。建议在方法开发阶段评估GAG链去除（ChABC处理）对效价测定的影响，确认生物活性来源于蛋白质骨架而非GAG链本身。

### 糖蛋白激素：受体介导细胞生物活性测定

#### EPO效价测定

**A. 细胞增殖法（体外法，推荐）**

| 参数 | 说明 |
|-----|------|
| 细胞系 | TF-1（GM-CSF依赖的红系前体细胞）或UT-7/EPO细胞 |
| 增殖读数 | CCK-8（450 nm）或[3H]-胸腺嘧啶掺入 |
| EPO受体信号通路 | EPO→EpoR→JAK2→STAT5→增殖 |
| 孵育条件 | 37°C, 5% CO₂, 72 h（TF-1细胞） |
| 剂量-效应 | S型曲线（4PL模型），平行线假设检验 |
| 效价表达 | 以WHO IRP溯源的内部参照标准品校准，以IU/mg报告相对效价（%） |
| CV要求 | 板内重复CV ≤15%，板间CV ≤25%（ADCC报告基因类似要求） |

**B. STAT5报告基因法（可选替代）**：工程细胞为EpoR+STAT5-荧光素酶报告基因细胞；优点是信号放大、灵敏度高、更低CV；需额外验证与原发信号通路（TF-1增殖法）的相关性。

**C. 体内法（大鼠网织红细胞增多法）**：适用场景为目标市场药典要求（ChP 2025三部、Ph.Eur. EPO专论）的法定方法；模型为低氧多血症小鼠或正常大鼠皮下注射EPO，测定注射后4–5天网织红细胞数量变化；参考标准为WHO EPO国际参考标准品（第4届IS，NIBSC 17/210，100 IU/ampoule）。2023年更新的第4届EPO国际标准品（NIBSC 17/210）适用于rEPO类产品的效价溯源。阶段策略见"特殊考量"章节。

#### FSH效价测定（FSH-CTP产品）

**A. 受体介导cAMP测定法（体外法，推荐）**

| 参数 | 说明 |
|-----|------|
| 细胞系 | KGN细胞（内源FSH受体），或CHO-FSHR工程细胞 |
| 信号通路 | FSH→FSHR→Gs蛋白→腺苷酸环化酶→cAMP升高 |
| 检测方法 | HTRF cAMP试剂盒（Cisbio）或AlphaScreen/ELISA |
| 孵育时间 | 30 min–1 h（cAMP刺激） |
| 剂量-效应 | S型曲线，4PL拟合 |
| 效价表达 | 相对效价（%），对标WHO FSH IRP溯源的内部参照品 |

**B. CRE-荧光素酶报告基因法（可选替代）**：CRE（cAMP response element）驱动荧光素酶的工程细胞；信号放大比cAMP直接测定更强、更灵敏；需验证与cAMP法的相关性。

**C. 体内法（大鼠卵巢重量增重法，Steelman-Pohley法）**：适用场景为药典要求（Ph.Eur. FSH专论）及生物类似药效价标定；模型为幼鼠皮下注射FSH 3天后测定卵巢重量（FSH促进卵泡发育）；高变异性（CV 25–35%），需大样本量，主要用于校准WHO IRP。

**FSH-CTP特有考量：** FSH-CTP（含促性腺激素C端肽延伸的长效FSH）与标准FSH受体的结合动力学不同，CTP的存在降低受体结合速率但延长受体占用时间。效价测定方法必须考虑此特性，建议采用包含分泌过程（模拟体内吸收）的细胞模型，或在数据解读中说明CTP对体外效价测定结果的影响。

#### hCG效价测定

**A. 受体介导cAMP测定法（体外法）**：细胞系为MA-10细胞（莱迪希细胞瘤，内源LH/hCG受体）或CHO-LHR工程细胞；LH/hCG受体（LHR，即LHCGR）与两者均有高亲和力结合；cAMP测定参数同FSH法。

**B. 体内法（大鼠腹侧前列腺重量法）**：幼鼠皮下注射hCG 3天，测定腹侧前列腺（ventral prostate）重量；传统药典法；高度依赖动物个体差异（CV 20–30%）。

**hCG特有考量：** hCG为α/β异二聚体，β亚基CTP区域含多个O-糖位点，高唾液酸化延长半衰期。体外测定中，hCG与LHR的结合亲和力（pM级）远高于LH，须确保检测体系能区分单体与二聚体活性，避免解离导致的效价低估。

### 抗体类：靶点结合活性测定

#### ELISA结合活性

- **间接/抗原包被ELISA（标准方法）**：目标抗原包被于96孔微孔板，梯度稀释样品与包被板孵育，结合的抗体用抗Fc-HRP二抗检测；TMB显色，450 nm读数，S型剂量-效应曲线；参数为EC50值，或相对结合活性（% vs. 参考标准）。
- **竞争/抑制ELISA（替代方法）**：标记参考品与样品竞争抗原结合，更准确地反映亲和力变化，适合比较不同批次间结合活性的细微变化。
- **双抗双靶点桥接ELISA**：一侧用靶点A包被（捕获双抗），另侧用靶点B（HRP或生物素标记）检测；仅同时具有双靶点结合能力的双抗才能产生信号；是验证双抗同时结合两个靶点的关键功能学测定。

#### SPR动力学分析（BIAcore/SPR系统）

| 参数 | 说明 |
|-----|------|
| 原理 | 芯片表面固定配体（抗原或捕获抗体），流动相注入分析物（mAb或抗原），实时监测折射率变化 |
| 主要输出 | 结合速率（kon）、解离速率（koff）、平衡解离常数（KD = koff/kon） |
| 芯片类型 | CM5（氨基偶联），SA（链霉亲和素-生物素），蛋白A（捕获mAb Fc区） |
| 优势 | 动力学参数精确，提供亲和力的机理信息 |
| 局限 | 通量低，对高亲和力相互作用（KD < 1 pM）的koff难以精确测定 |
| 验证要点 | 配体固定密度、参考通道设计（无配体空白减除）、质量传递效应（mass transport）评估 |

双抗SPR分析：依次注入两种抗原（先A后B），确认双特异性结合（sequential binding），计算各靶点独立的动力学参数。

#### BLI亲和力分析（Octet系统）

| 参数 | 说明 |
|-----|------|
| 原理 | 光纤传感器尖端固定配体，分析物结合/解离引起生物层干涉信号变化 |
| 主要输出 | kon、koff、KD（与SPR可比） |
| 传感器类型 | Protein A（捕获mAb Fc），SA（链霉亲和素-生物素抗原），AHC（抗Fc）等 |
| 优势 | 相比SPR通量更高（8通道并行），操作更简便，适合QC设置 |
| 验证要点 | 传感器批次一致性，参考通道校正，数据全局拟合 |

QC应用推荐：BLI因操作简便、通量适中，推荐作为抗体结合活性的常规QC检测方法；SPR保留用于开发阶段详细动力学研究及方法建立阶段。

### 抗体类：Fc效应功能测定

#### ADCC（抗体依赖细胞介导的细胞毒性）

**A. 原代细胞法（PBMC法或NK细胞法）**

| 参数 | 说明 |
|-----|------|
| 效应细胞 | PBMC（外周血单个核细胞）或纯化NK细胞（主要效应细胞） |
| 靶细胞 | 表达目标抗原的肿瘤细胞系 |
| E:T比例 | 通常25:1–50:1（PBMC:靶细胞） |
| 裂解检测 | LDH释放法（非放射性，Promega CytoTox 96）或流式PI染色 |
| 精密度 | 供体间变异高（CV 20–40%），不适合批次放行 |
| 适用场景 | 开发阶段机理验证，可比性研究中高灵敏度参考 |

**B. 报告基因ADCC替代法（推荐用于常规QC）**

| 参数 | 说明 |
|-----|------|
| 细胞系 | Jurkat/NFAT-荧光素酶/FcγRIIIa（CD16a）V158变体（高亲和力型）工程细胞 |
| 原理 | 靶细胞表面抗原×mAb的Fc×FcγRIIIa（CD16a）三元复合物激活NFAT信号→荧光素酶表达 |
| 靶细胞 | 同原代细胞法，选用内源高表达目标抗原的细胞系 |
| E:T比例 | 通常6:1（Jurkat:靶细胞） |
| 孵育时间 | 6 h，37°C, 5% CO₂ |
| 信号检测 | 荧光素酶底物（One-Glo试剂），发光计数仪 |
| 精密度 | CV通常 ≤15%（中间精密度），显著优于原代细胞法 |
| 监管接受度 | FDA/EMA已接受报告基因ADCC作为等效替代方法，须提供与原代细胞法的相关性验证数据 |
| 商业试剂盒 | Promega ADCC Reporter Bioassay（FcγRIIIa，稳定转染Jurkat细胞）——已有大量文献支持 |

**糖基化影响：** Fc区Asn297糖型（特别是岩藻糖化程度）直接影响FcγRIIIa结合亲和力和ADCC活性。去岩藻糖化（afucosylation）可提升ADCC 50–100倍。报告基因法对此高度敏感，批次间岩藻糖化程度变化可在ADCC效价结果中反映，具有作为间接糖型监控工具的潜力。

#### CDC（补体依赖性细胞毒性）

| 参数 | 说明 |
|-----|------|
| 补体来源 | 商业化新鲜婴兔补体（Low-Tox-M Rabbit Complement）或人血清补体 |
| 靶细胞 | 高表达目标抗原的细胞系（如Raji、Daudi、Ramos用于CD20/CD19） |
| 检测方法 | LDH释放（Promega CytoTox）、PI染色（流式）或发光法 |
| 补体变异 | 补体批次间活性差异大，须进行批次筛选和校准 |
| 适用范围 | 依赖CDC发挥作用的抗体（如利妥昔单抗类抗CD20 mAb）；如MoA不含CDC则通常不要求 |

注意：并非所有治疗性抗体均需进行CDC测定。须基于产品MoA明确CDC是否是临床相关效应机制。例如，皮下注射单抗若MoA主要为靶点中和/阻断而非细胞毒性，CDC测定的必要性须与监管机构讨论。

#### ADCP（抗体依赖细胞吞噬）及FcγR结合

| 测定类型 | 方法 | 适用场景 |
|---------|------|---------|
| ADCP（吞噬） | 巨噬细胞/中性粒细胞吞噬荧光标记靶细胞，流式定量吞噬% | MoA含ADCP的产品（如抗CD38等） |
| FcγRIIa结合（CD32a） | ELISA/SPR/BLI测定FcγRIIa结合 | ADCP预测，炎症相关效应 |
| FcγRIIIa结合（CD16a） | ELISA/SPR/BLI测定FcγRIIIa结合 | ADCC潜力预测；与ADCC活性高度相关 |
| FcRn结合（新生儿Fc受体） | SPR/BLI测定pH 6.0条件下FcRn结合（释放pH 7.4）| SC给药半衰期预测；IgG再循环机制 |

SC单抗FcRn考量：皮下注射单抗的体内半衰期受FcRn介导的IgG再循环机制控制。批次间pH 6.0条件下的FcRn结合亲和力变化，可作为半衰期相关CQA的监控指标，建议纳入PPQ批次的功能学表征。

### 方法选择原则与验证要点

#### 体内法 vs. 体外法

| 考量维度 | 体内法（in vivo） | 体外法（in vitro）替代法 |
|---------|-----------------|----------------------|
| 监管地位 | 药典规定法（prima facie合规），历史认可 | 须完整验证 + 与体内法的相关性证明 |
| 精密度 | 低（CV 20–40%），需大动物量 | 高（CV 10–20%），样品量少 |
| 通量 | 低（每次30–60天，大量动物）| 高（96孔板，3–7天） |
| 动物福利 | 消耗大量动物，与3R原则（Replacement, Reduction, Refinement）矛盾 | 符合3R，监管机构积极鼓励转换 |
| 监管趋势 | Ph.Eur./ChP逐步接受体外替代（须经申报批准） | FDA/EMA已广泛接受验证的体外替代方法 |
| 策略建议 | 早研阶段以体外法为主；如目标市场（中国/欧盟/美国）强制要求体内法，须在BLA前建立并申报体外替代法 |

#### 药典方法 vs. 自建替代方法

| 考量维度 | 药典法 | 自建替代法 |
|---------|--------|----------|
| 监管接受 | 自动合规（prima facie） | 须经ICH Q2(R2)完整验证 + 监管批准 |
| 灵活性 | 低（条件固定，修改需申报） | 高（可针对产品特性优化） |
| 精密度 | 通常中等（V法方差大） | 可实现更高精密度 |
| 推荐策略 | 早期开发中采用药典法建立初步效价基准；BLA前建立更适合常规QC的替代方法并申报批准；维持药典法作为仲裁方法 |

#### 生物活性测定方法验证关键参数（基于ICH Q2(R2)和USP ⟨1033⟩）

| 验证参数 | 定义 | 生物活性测定接受标准 | 备注 |
|---------|------|------------------|------|
| 专属性（Specificity） | 方法准确区分目标生物活性与非特异性信号的能力 | 阳性对照/阴性对照/特异性阻断剂验证 | 阴性对照（无活性样品）不产生信号 |
| 线性与范围（Linearity & Range） | 剂量-效应的线性（或4PL模型适用）范围 | 通常50–200%（%相对效价），4PL全范围；线性性用于特定范围如80–125% | 4PL模型不要求线性，但须证明平行性 |
| 准确度（Accuracy） | 测定结果与真实效价值的接近程度 | 回收率80–120%（相对参考标准品） | 用稀释线性回收率或加标回收率验证 |
| 重复性（Repeatability） | 同一分析员、同一天、同一实验室内的精密度 | CV ≤ 15%（板内），优选CV ≤ 10% | 同日≥6次重复或≥3批次各≥2次重复 |
| 中间精密度（Intermediate precision） | 不同分析员、不同天、同一实验室内的精密度 | CV ≤ 25%，优选CV ≤ 20% | ≥3天、≥2位分析员 |
| 稳健性/耐用性（Robustness） | 关键参数小幅波动对结果的影响 | 关键参数（细胞传代数、血清批次、孵育时间、温度）各测定一次高低值 | 筛选出系统适用性标准（Suitability Criteria） |
| 系统适用性（SSC） | 每次实验通过/失败的内建标准 | Z'因子 ≥ 0.5（筛选实验），参考标准品EC50在历史均值±30%内 | 参考标准品批次一致性须定期校准 |
| 平行性（Parallelism） | 样品剂量-效应曲线与参考标准曲线的形状一致性 | F检验或似然比检验，p > 0.05为通过（无显著差异） | 平行性失败提示基质差异或样品质量问题 |

## 全生命周期阶段研究策略

### IND申报阶段

IND阶段的目标是建立各产品的初步效价/生物活性测定方法，证明候选分子具有预期生物学功能；为IND申报CTD资料提供必要的功能学数据（生物活性初步表征）；建立初步的参考标准品效价基线（对接WHO IRP或国家标准品）；通过初步方法确认，证明方法基本适用并满足放行检验需求。

批次要求：毒理批次≥1批（实验室/中试规模），须确认毒理批次具有生物活性（支持毒理学研究设计和剂量选择）；GMP批次≥1批（中试规模），须完成全套IND阶段功能学检测（含效价、结合活性，抗体类须含ADCC初步数据）。

IND阶段各产品类型的必须/建议检测项：

| 产品分类 | 必须完成（●） | 建议完成（○）|
|---------|------------|------------|
| **酶类** | 效价测定（酶活/TIU单位，≥1种经确认方法） | 酶动力学参数（Km/Vmax），底物特异性初探 |
| **糖蛋白激素** | 体外细胞效价（细胞法+初步剂量-效应曲线），参考标准品EC50基线 | 体内法初步建立（目标药典市场要求时）；与WHO IRP的初步相对效价 |
| **单抗（SC）** | 靶点结合活性（ELISA EC50或BLI KD初步值）；初步细胞效价（细胞中和/激动剂法） | ADCC报告基因法初步评估；FcRn结合初探 |
| **双特异性抗体** | 两个靶点分别的ELISA结合活性；双靶点桥接ELISA初步 | ADCC报告基因法（如含Fc效应功能）；双功能细胞效价初步 |

IND阶段不要求完整方法验证（Full Validation），须完成**方法确认（Qualification）**，证明方法基本适用：

| 确认参数 | 最低要求 |
|---------|---------|
| 准确度（初步）| 参考标准品回收率 80–120%（≥3次重复） |
| 精密度（初步）| 板内CV ≤ 20%（≥3次重复） |
| 线性/范围 | 展示至少50–200%的S型剂量-效应曲线 |
| 平行性（初步）| 样品与参考品平行性定性判断 |
| 系统适用性 | 初步设定参考标准品EC50接受范围 |

> **不要求：** 完整的中间精密度验证、稳健性研究、多实验室转移验证——这些在BLA阶段完成。

IND申报CTD资料位置：3.2.S.3.2（原液效价初步表征结果）、3.2.S.4.1（质量标准草案，效价作为必须检验项目，标准暂定）、3.2.S.4.2（效价测定方法描述）、3.2.S.4.3（方法确认数据摘要）、3.2.P.4.2（制剂效价检验方法）、3.2.P.4.3（制剂效价方法确认数据）。

### 临床期间

临床期间通过每批临床批次效价放行检验维持批次间生物活性的一致性监控；当发生工艺变更时执行功能可比性评估（ICH Q5E）；逐步积累用于支持BLA申报的功能学历史数据；在方法确认基础上持续推进方法优化和验证。

常规临床批次功能学监测：

| 监测内容 | 频率 | 要求 |
|---------|------|------|
| 效价测定（I类功能） | 每批放行 | 纳入放行标准，须在预设的效价接受范围内 |
| 靶点结合活性（II类，抗体） | 每批放行 | ELISA EC50相对效价 |
| 扩展功能学（ADCC、SPR动力学等）| 代表性批次（各临床阶段≥1批）| 不作为放行项目，用于趋势监控 |

工艺变更时的功能可比性评估（基于ICH Q5E）：

| 变更类型 | 功能可比性评估要求 | 批次数 |
|---------|----------------|-------|
| 生产规模放大（中试→商业化）| 全套I类+II类+III类（适用产品）并行测定，变更前后批次平行比较 | 变更前≥1批，变更后≥2批 |
| 生产场地变更 | 同上 | 同上 |
| 培养基/原材料变更 | I类效价必须；II类和III类视变更对糖型/结构的风险评估决定 | 变更前≥1批，变更后≥1批 |
| 纯化工艺步骤变更 | I类效价；对纯度/杂质有影响的还须排除杂质干扰效价的可能 | 变更前≥1批，变更后≥1批 |
| 处方变更（制剂）| 在制剂成品层面重新进行效价测定，考察处方辅料对生物活性的影响 | 变更前后各≥1批制剂批次 |

功能可比性判断标准：变更后样品效价（相对效价%）应在变更前历史批次范围内（通常80–120%），或统计学分析表明差异不具有临床显著性。如出现系统性偏移，须启动可比性风险评估，可能需要临床数据补充。

参考标准品更换时须进行新旧批次效价桥接测定，确保效价单位的连续性：新旧参考标准品在同一批独立实验中平行测定（≥3天，每天≥2次重复），计算新旧对照品的相对效价比值（Potency Ratio）；接受标准为效价比值的95%置信区间应包含1.0（或在0.90–1.10范围内）；以经桥接确认的新对照品替换旧批次，所有后续测定以新对照品为基准报告效价。参考标准品的标定与溯源策略详见**模板5：对照品制备及标定策略**。

### BLA申报阶段

BLA阶段提供完整功能学数据包，支持BLA申报（CTD 3.2.S.3.2 / 3.2.S.4.2 / 3.2.S.4.3）；完成基于ICH Q2(R2) + USP ⟨1033⟩的完整分析方法验证（Full Validation）；证明PPQ商业化批次的功能一致性（效价批间一致性）；确立效价的接受标准和历史范围（Action Limits）。

PPQ批次要求：≥3批，商业化规模（最终放大规模），拟上市包装规格，经验证的最终商业化工艺；三批并行完整功能学测定（I类+II类+III类适用项目全部●项）。

BLA申报前，所有纳入质量标准的功能学测定方法须完成基于ICH Q2(R2)的完整验证：

| 验证项目 | 要求概述 |
|---------|---------|
| 专属性 | 证明方法仅对目标生物活性特异响应（阴性对照、结构类似物干扰排除） |
| 线性与范围 | 4PL模型拟合R² ≥ 0.99；有效工作范围50–200% |
| 准确度 | ≥3水平（80%、100%、120%），各水平3次重复，回收率80–120% |
| 重复性（板内精密度）| ≥6次重复，CV ≤ 15% |
| 中间精密度 | ≥3天，≥2位分析员，CV ≤ 25% |
| 平行性 | 统计学检验，验证样品与参考品的平行剂量-效应 |
| 耐用性/稳健性 | ≥5项关键参数分别考察高低值；确认关键参数控制范围 |
| 方法转移（如适用）| 若跨实验室或跨机构执行，须完成方法转移验证 |

BLA功能学数据包：全部临床批次+PPQ批次效价历史数据（批间一致性分析、趋势图）；PPQ 3批全套功能学检测（含靶点结合、Fc效应功能适用项）；效价与WHO IRP或国家标准品的相对关系及参考品标定数据；全套ICH Q2(R2)验证数据，每项功能学方法独立验证报告。

BLA申报CTD资料位置：3.2.S.3.2（原液全面功能学表征）、3.2.S.4.1（质量标准，效价最终接受标准和方法）、3.2.S.4.2（分析方法完整描述，含系统适用性标准）、3.2.S.4.3（完整方法验证报告）、3.2.P.4.2（制剂功能学检测方法）、3.2.P.4.3（制剂功能学方法验证报告）。

### 上市后监测与方法生命周期管理

上市后通过批次放行效价检验持续监控产品生物活性，及时发现工艺漂移；维持效价趋势数据，支持年度产品回顾（APR）；为再注册和上市后变更管理提供功能学基础数据。

| 监测类型 | 频率 | 批次选择 | 监测范围 |
|---------|------|---------|---------|
| 批次放行效价 | 每批 | 全部商业化批次 | 效价测定（I类），纳入放行标准 |
| 年度趋势分析 | 每年 | 当年全部放行批次 | 效价均值、CV、OOT趋势，APR汇总 |
| 变更后功能评估 | 变更实施后 | 变更后首批 | 按可比性策略执行 |

分析方法生命周期管理（ICH Q12框架）：效价测定方法的关键参数如归入"既定条件"（Established Conditions, ECs），变更须向监管机构申报；方法改进（如更换细胞系批次、试剂批次）应按内部变更管理SOP执行，并进行方法桥接确认；持续验证（Continued Method Validation）要求每年评估历史系统适用性数据（SSC通过率、EC50漂移趋势），识别方法性能退化的早期信号。

## 特殊考量

### 体内生物活性检测的阶段性使用策略

| 研发阶段 | in vivo法策略 | in vitro替代法策略 |
|---------|-------------|-----------------|
| 早研/候选分子筛选 | 通常不要求体内法 | 建立体外效价筛选方法 |
| IND阶段 | 若目标市场药典要求，须建立体内法或提供替代证据 | 体外法作为主要效价方法；启动体内/体外相关性积累 |
| 临床阶段（Ⅰ/Ⅱ期）| 若药典要求，体内法可暂作为放行参考；与体外法平行进行 | 积累≥20批次的体内外平行数据，用于相关性论证 |
| BLA阶段 | 若已建立充分的体内外相关性（≥20批次，r² ≥ 0.9），可申报以体外法替代体内法 | 提交完整替代法验证包（含相关性研究），向目标市场监管机构申报 |
| 上市后 | 按申报批准的方法执行 | — |

**EPO体内法（大鼠网织红细胞增多法）**：幼龄大鼠皮下注射受试品，注射4–5天后采血测定网织红细胞（reticulocyte）计数。EPO刺激骨髓红系前体细胞增殖分化，导致血液中网织红细胞数量显著增加。关键参数（参考ChP/Ph.Eur.方法**【待核实具体章节】**）：动物为8–10周龄雄性Wistar大鼠或SD大鼠；皮下注射，2次/天×3天（或根据药典规定）；检测指标为给药后第5天网织红细胞百分比（Reticulocyte count by flow cytometry）；剂量设计为3–5个剂量水平，平行线生物测定（Parallel line assay）；参考标准为WHO EPO IRP（第4届，NIBSC 17/210, 2023年）。体外替代为TF-1增殖法，须在中国/欧盟/美国BLA申报前完成相关性论证和方法变更申报。

**FSH体内法（Steelman-Pohley法）**：幼龄雌鼠（21天龄）同时注射FSH（受试品）+hCG（固定量），连续3天，第4天测定卵巢湿重。FSH促进卵泡发育→卵巢增重。关键参数（参考Ph.Eur. FSH专论**【待核实具体编号】**）：21±1日龄雌性Wistar大鼠，每组≥6只；合并给药为FSH（受试品）+固定量hCG（促进LH受体表达，放大FSH效应）；检测指标为第4天卵巢湿重（mg）；剂量设计为3剂量平行线设计；参考标准为WHO FSH IRP（NIBSC 83/575，5000 IU/ampoule）。

**hCG体内法（大鼠腹侧前列腺重量法）**：幼龄雄鼠（21天龄）皮下注射hCG（受试品），连续3天，第4天测定腹侧前列腺（ventral prostate）湿重。hCG通过LH受体刺激睾丸Leydig细胞产生睾酮，间接促进前列腺增重。关键参数（参考Ph.Eur. hCG专论**【待核实具体编号】**）：21±1日龄雄性SD大鼠，每组≥6只；检测指标为第4天腹侧前列腺湿重（mg）；参考标准为WHO hCG IRP（第4届，NIBSC 75/537或更新版）。

### 可比性研究中的功能学评估（ICH Q5E）

功能学评估是可比性研究中不可省略的核心维度。制造工艺变更时，须选择覆盖产品全部已知MoA的功能学测定组合：

| 产品类型 | 可比性功能学测定组合 |
|---------|------------------|
| 重组酶 | 效价（同法定方法），酶动力学参数（Km/Vmax初步比对） |
| EPO/FSH/hCG | 体外细胞效价（4PL拟合，相对效价%），如有糖型变化还须评估唾液酸化程度对效价的影响 |
| 单抗 | ELISA结合活性 + 细胞效价 + ADCC报告基因法 + FcγRIIIa/FcRn结合（SPR/BLI） |
| 双抗 | 双靶点ELISA（各靶点独立）+ 桥接ELISA + 细胞双功能效价 |

评估结论原则（基于ICH Q5E）：结果相似→工艺变更经功能学确认，可进入下一步批准流程；结果存在可辨识差异→评估差异的临床影响；若超出已知变异范围，须考虑是否需要临床可比性研究。

### 生物类似药功能学相似性评估

依据FDA 2025年9月最终版《Development of Therapeutic Protein Biosimilars: Comparative Analytical Assessment》和EMA/CHMP/BWP/247713/2012，生物类似药功能学比较须满足：

| 要求维度 | 内容 |
|---------|------|
| 批次数 | 候选药≥3批（不同生产批次，覆盖代表性变化）vs. 参照药≥3批（包含不同上市地区、不同批次）|
| 测定范围 | 候选药与参照药头对头比较，覆盖产品所有已知MoA（效价 + 结合 + Fc效应功能，视适用） |
| 统计分析 | 功能学相似性应基于统计学评估（置信区间方法，以90% CI包含于预设等效区间为优先）|
| 体外法优先 | 优先采用已验证的体外法进行比较；体内法仅在体外法不能充分反映生物活性时使用 |
| MoA全覆盖 | 功能测定须覆盖参照药所有已知MoA；多机制产品须针对每种机制分别设计比较实验 |

### 双特异性抗体功能学特殊考量

双特异性抗体的功能学表征远比单抗复杂，须额外设计以下验证：

| 功能学类型 | 验证要点 |
|---------|---------|
| 靶点A独立结合 | 单独针对靶点A的ELISA/BLI/SPR，验证结合亲和力和特异性 |
| 靶点B独立结合 | 单独针对靶点B的ELISA/BLI/SPR，验证结合亲和力和特异性 |
| 双靶点同步结合（桥接）| 以靶点A捕获，靶点B检测（或反向），仅双功能分子产生信号；验证两臂同时结合能力 |
| 双功能细胞效价 | 若为T细胞重定向格式（如BiTE）：肿瘤细胞/T细胞共培养杀伤实验；若含Fc效应功能：ADCC报告基因法 |
| 链配对比例 | 非对称格式须验证异源二聚体比例（功能形式），评估同源二聚体杂质对功能学结果的影响 |
| Fc效应功能 | 若含Fc区，同单抗策略（ADCC/CDC/ADCP视MoA适用）|

| 生物活性测定 | Bioassay | 通过测量生物体（细胞、动物等）对样品的反应来测定样品生物活性的分析方法，包括细胞法、酶活法和体内法 |
| 方法确认 | Method Qualification | 早期阶段的简化方法验证，证明方法基本适用，收集准确度、精密度初步数据，不要求完整的ICH Q2参数 |
| 完整方法验证 | Full Method Validation | 基于ICH Q2(R2)的完整分析方法验证，涵盖专属性、线性、范围、准确度、精密度、耐用性等全套参数 |
| 平行性 | Parallelism | 样品与参考标准品剂量-效应曲线形状的一致性；平行性失败提示样品基质效应或活性形式与参考品不同 |
| 相对效价 | Relative Potency | 样品效价相对于参考标准品效价的比值，以%表示；通过4PL拟合的EC50比值计算 |
| 国际参考标准品 | International Reference Preparation (IRP) | WHO/NIBSC建立的生物制品国际标准品，用于效价溯源；活性单位以国际单位（IU）定义 |
| ADCC报告基因法 | ADCC Reporter Bioassay | 以Jurkat/NFAT-荧光素酶/FcγRIIIa工程细胞替代原代NK细胞测定ADCC效应的替代方法，精密度优于原代细胞法 |
| Fc效应功能 | Fc Effector Functions | 通过Fc区介导的效应机制，包括ADCC（FcγRIIIa介导）、CDC（C1q介导）、ADCP（FcγRIIa介导）等 |
| FcRn | Neonatal Fc Receptor | 新生儿Fc受体，通过pH依赖性结合保护IgG免于溶酶体降解，是IgG长半衰期的主要机制；SC单抗体内暴露的关键决定因素 |
| 4PL | Four-Parameter Logistic | 四参数逻辑斯谛模型（S型曲线），最小值-最大值-EC50-Hill斜率，是生物活性测定剂量-效应数据拟合的标准模型 |
| TIU | Trypsin Inhibitory Unit | 胰蛋白酶抑制单位，Kunitz法测定酶抑制剂（如乌司他丁）效价的国际通用单位 |
| 系统适用性标准 | System Suitability Criteria (SSC) | 每次生物活性测定实验前/中/后须满足的通过/失败标准，包括参考标准品EC50范围、Z'因子等 |
| MoA | Mechanism of Action | 作用机制，即产品发挥临床效果的生物学途径；功能学测定方法须覆盖产品的全部已知MoA |
