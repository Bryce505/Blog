本文以 Schilling 2015（Mol Microbiol 98:847–863）提出的"碳溢流 → 乙酰磷酸（acetyl phosphate, AcP）累积 → 非酶促赖氨酸乙酰化"为唯一机制依据，把该文献的实验结论逐条翻译成发酵上游可操作的工艺杠杆（收获时相、补糖/碳流、溶氧、温度、乙酸、宿主基因型），并给出 DoE 设计、过程读数、判读标准与不可外推的证据边界。全文按"机制事实 → 与本品的对接 → 杠杆清单 → 实验设计 → 适用边界"的顺序组织，重点在于说明哪些结论可以直接用、哪些只是外推。

## 结论与报告的定位

> [!abstract] 一句话结论
> Schilling 2015 给出的是一条**可被上游直接干预的因果链**：**碳流超过中央代谢处理能力（碳溢流）→ 乙酰磷酸（acetyl phosphate, AcP）累积 → AcP 以非酶促方式把乙酰基交给赖氨酸 ε-氨基 → 蛋白乙酰化**。它把"乙酰化"从"随机化学损伤"变成了"代谢状态的可读数"。
>
> 因此，降低本品酸性峰中乙酰化组分的上游策略，**不是"找一个最优温度"，而是"在整个发酵过程中不让碳流超过细胞的氧化/同化能力"**。按预期杠杆从大到小排列：**①收获时相与诱导后时长 → ②补糖/碳流策略（残余葡萄糖与比生长速率）→ ③溶氧与营养平衡（防发酵性溢流）→ ④温度 → ⑤宿主基因型（AckA/Pta 收支）**。
>
> **但必须先读本文的「证据边界」与「风险、反例与不可外推之处」两节**：该文测的是 **K-12 宿主自身蛋白**在 **摇瓶/TB7/37 ℃/0.4% 葡萄糖分批**条件下的乙酰化，不是重组产物、不是高密度补料发酵。本报告的应用属于**机制外推 + 需在本品工艺上实测验证**的推论，不能当作已验证结论写入申报材料。

> [!warning] 三条"先决条件"——不满足则本报告的工艺建议无效
> 1. **先证明 +42 是体内真实修饰，而不是分析前处理假象**。库内既往已明确：尿素制样可引入 +43，且抗乙酰赖氨酸抗体会**共纯化氨甲酰化肽**，+42/+43 在富集与搜库层面会互相污染。必须做"尿素-free vs 含尿素"平行酶切对照。
> 2. **先确认 +42 落在产物上、且落在 Lys（而非 N 端）**。本文的机制只解释 **Lys Nε 乙酰化**；N 端 Nα 乙酰化是另一条（酶促、共翻译）路径，本文的工艺杠杆对它基本无效。
> 3. **先区分"自研 vs 原研"的差值**。只有当"自研−原研"的乙酰化化学计量差能够定量解释酸性峰差值（用 `1−exp(−Σpᵢ)` 量级自洽性判据）时，上游降乙酰化才是有意义的攻关方向。

## 文献核心结论：六条机制事实与关键定量数据

| # | Schilling 2015 的实验事实 | 机制含义 | 对应的上游抓手 |
|---|---|---|---|
| 1 | 葡萄糖（或乳酸）诱导的全局乙酰化**随时间单调升高**；**绝大部分发生在进入稳定期之后**（4 h 后），与**葡萄糖消耗速率**和**乙酸外排**同步 | AcP 的**供给速率**才是自变量；乙酰化是碳代谢通量的"读数" | **收获时相 / 诱导后时长**（杠杆最大） |
| 2 | **12 h 加葡萄糖**测得 2338 个 Kac 位点 / 705 个蛋白；**12 h 不加葡萄糖**仅 451 个位点 / 216 个蛋白；加糖组 1081 个位点的乙酰化显著升高（中位 **7.5 倍**） | 碳源的存在与通量决定乙酰化的**数量级**差异，不是细微调节 | **碳源种类、碳源投加总量与投加速率** |
| 3 | 葡萄糖**必须在不晚于 3 h 加入**才能诱导最强乙酰化；4 h 加入效应大幅减弱；5–6 h 加入**不产生**乙酰化；且必须**在稳定期持续存在**于培养基中 | 存在**"诱导窗口"**与**"碳源持续暴露"**两个必要条件 | **补糖起始时点、补糖持续时间、末期是否继续供碳** |
| 4 | 敲除 **ptsG**（葡萄糖 PTS 转运体）→ 葡萄糖诱导的乙酰化**消失**，表型等同于不加糖 | 碳源**摄入速率**是上游限速环节，不只是"有没有糖" | **葡萄糖摄入速率控制**（低残余糖补料 / 非 PTS 碳源） |
| 5 | 敲除 **crp** 或 **cya** → 乙酰化**大幅丧失**（24 h 仍低）；在 **pta ackA** 双缺失背景下过表达 CRP 对全局乙酰化**几乎无影响** → 说明大部分 CRP 依赖型乙酰化**需要 AcP**；反过来 **ΔackA**（AcP 不能被转成乙酸）→ 乙酰化**高于**野生型；在 ΔackA 上再敲 crp 只**轻微**降低 → **高 AcP 可部分绕过 CRP** | AcP 是**汇聚节点（hub）**：上游是碳流/CRP，下游是乙酰化 | **宿主基因型**（AcP 收支）——最高杠杆，但监管成本最高 |
| 6 | 同一蛋白的不同赖氨酸**乙酰化速率与幅度差异很大**（如 IDH 的 8 个位点、MDH 的 10 个位点各自成谱）；~90% 的受调控位点**同时**依赖时间与葡萄糖；富集通路为糖酵解/糖异生、磷酸戊糖途径、TCA 循环、丙酮酸代谢等中央代谢 | 非酶促 ≠ 无选择性：位点特异性由**可及性、反应性与三维微环境**决定 | 意味着**降低 AcP 会按比例降低全部 AcP 依赖位点**，但不会归零；不必追求"某一位点清零" |

| 观测 | 数值 |
|---|---|
| 葡萄糖时程中鉴定的 Kac 位点数 | 2 h **1068** → 5 h **1658** → 8 h **2226** → 12 h **2338** |
| 对应乙酰化蛋白数 | 2 h 395 → 5 h 540 → 8 h 671 → 12 h 705 |
| 加糖 vs 不加糖（12 h） | 2338 位点/705 蛋白 **vs** 451 位点/216 蛋白 |
| 显著上调的位点（加糖 vs 不加糖） | **1081** 个 Lys / **406** 个蛋白，中位升高 **7.5 倍** |
| 时程相对变化中位数 | 5 h/2 h **2.7×**；8 h/2 h **5.7×**；12 h/2 h **6.6×** |
| 跨全部时点均检出的位点 | **889** 个（说明有大量"一直存在但水平上升"的位点） |
| 多位点蛋白比例 | **30%** 的乙酰化蛋白带 > 3 个 Kac 位点 |
| 通路富集（加糖 vs 不加糖） | 糖酵解/糖异生、磷酸戊糖途径、TCA 循环、丙酮酸代谢、谷胱甘肽代谢、乙醛酸/二羧酸代谢、脂肪酸合成等 |

> [!important] 第 5 条的"反例"必须记住：**乙酸低 ≠ AcP 低**
> Schilling 的遗传学结果是：**ΔackA（少了 AcP→乙酸这一步）乙酰化反而升高**。所以**不能**把"发酵液乙酸浓度低"直接等同于"AcP 低、乙酰化低"。乙酸外排速率是**乙酸开关通量**的读数，而 AcP 的稳态浓度取决于 **Pta 生成速率（AcCoA + Pi → AcP + CoA）与 AckA 消耗速率**之间的差。
> **可操作含义**：把乙酸当作**趋势性过程指标**（用于发现溢流发生的时段），而把**胞内 AcP 实测**或**产物乙酰化定点定量**当作**决定性指标**。

## 机制链条与 Fc–TPO 肽融合蛋白的对接

### 为什么 AcP 依赖型 Lys 乙酰化很可能就是本品 +42 的来源

| 项目 | 内容 | 对上游调控的意义 |
|---|---|---|
| 架构 | 269 aa/链 × 2，**N 端 Met–Asp，肽在 Fc 的 C 端** | N 端 Nα 乙酰化可能性低（E. coli Nα-乙酰转移酶偏好 Ser/Ala/Thr）→ **+42 更可能是 Lys Nε** → **正好落在本文可解释、可上游调控的路径上** |
| 可反应位点 | **40 个 Lys ε-氨基 + 2 个 N 端 α-氨基 / 二聚体**（肽段不含 Lys） | 位点多、单位点占位低 → **降低 AcP 的收益是"面"上的**，容易被常规肽图漏报，必须专门定量 |
| 电荷后果 | 乙酰化 +1 → 0（净减一个正电荷） | 每位点一个电荷步进 → 多峰（电荷阶梯），与"多重酸性峰"形态相容 |
| 已确认的旁证 | 自研存在 **+178 Da 葡萄糖酰化**（N 端 α-氨基被 6-磷酸葡萄糖酸内酯进攻） | 证明**该分子的亲核位点在工艺中可及、有反应性**；同一 N 端位点也是 +42/+43 的候选靶点 |

> [!tip] 一个能立刻用上的"指纹判据"
> AcP 依赖型乙酰化的**预期指纹是"多位点、低化学计量、随碳流与收获时相漂移"**。
> - 若肽图显示**多条肽段各带少量 +42**，且**随发酵时间延长而同步升高** → 与本文机制一致，**上游优化有效**。
> - 若 **+42 只集中在单一条肽段且比例很高**（尤其是 N 端肽段）→ 应优先怀疑 Nα 乙酰化、或名义 +42 的三甲基化（+42.0470）、或质量校准误判；**本文的工艺杠杆对它无效**。

### 包含体产物特有的逻辑：乙酰化只可能"在体内、且在上游"获得

- AcP 是**胞内代谢物**；体外复性液（碱性尿素 + 氧化还原对）中**没有 AcP、也没有乙酰-CoA**。
- 因此，产物上的 +42 **只能在细胞内获得**——即从**翻译完成**到**被包进包含体（或经分泌/可溶途径）**之间的**胞质暴露窗口**内。
- 结果是：产物的乙酰化程度 ≈ **胞质内 AcP 浓度 × 产物在胞质中以可及构象存在的停留时间**。

**由这条推理直接导出的两个非显然结论：**

1. **下游复性/纯化工艺无法去除或减少乙酰化**（不像 +43 那样有"减少碱性尿素暴露"这条下游路径）。**乙酰化只能靠上游解决**——这正是本报告存在的理由。
2. **"让产物更快地进入包含体"在理论上是降低暴露窗口的手段，但它以正确折叠/可复性为代价**，且会与文献第 1 条（乙酰化随时间累积）在方向上相互纠缠。**不要把它当作首选杠杆**；应先做时相与碳流，再评估表达速率。

### 一张图看清"水龙头与排水口"

```
                    ┌──────────── 进水（打开 = 乙酰化升高）────────────┐
  碳源（葡萄糖/甘油/乳酸）
        │  PTS 摄入（ptsG）              cAMP–CRP（cya/crp）
        ▼                                      │ 转录调控
   糖酵解通量 ────► 乙酰-CoA ──┐               │
        │                      │ Pta           │
        │ 超过 TCA/氧化能力      ▼               ▼
        │  = 碳溢流          【乙酰磷酸 AcP】◄── 中央代谢酶的表达谱
        │                      │
        │                      │ AckA（AcP + ADP → 乙酸 + ATP）  ← 排水口①（开大 = 乙酰化降低）
        │                      ▼
        │                   乙酸外排 ──► 发酵液乙酸 ↑（表观读数，非直接指标）
        │
        └─► 产物（胞质暴露窗口）── 被 AcP 非酶促乙酰化 ──► +42

   已形成的 +42：CobB（NAD+ 依赖去乙酰化酶）  ← 排水口②（只能逆转一部分位点）
```

**读图要点**：进气量由**碳流**决定，排水口①由 **AckA 活性**决定。Schilling 的 ΔackA 实验（关掉排水口①）使乙酰化升高，正是这张图最直接的验证。上游工艺能调的是**进气量**；菌株工程能调的是**排水口**。

## 上游优化杠杆：按"预期收益 / 实施成本"排序的 A/B/C 三级

分级标准：**A 级**＝低监管成本、可直接试（工艺参数）；**B 级**＝需验证，中等成本；**C 级**＝菌株遗传改造，最高收益但最高监管成本。

### A1. 收获时相与诱导后时长——第一杠杆

| 项 | 内容 |
|---|---|
| **文献依据** | 乙酰化"绝大部分发生在进入稳定期之后"；加糖组位点数 2 h→12 h 由 1068 增至 2338；同一批位点的乙酰化水平持续上升（12 h/2 h 中位 6.6×）；且"必须在稳定期持续暴露于碳源"才发生 |
| **可操作形式** | 建立**诱导后时间梯度**（例如 4/6/8/10/12/16 h，或按 OD/产物累积量设点），每点同时测：①产物量；②产物**特定位点 +42 化学计量**（靶向 MS）；③IEC 酸性峰% |
| **预期** | 存在一个"膝点"：在膝点之前延长发酵，乙酰化上升缓慢；过膝点后急剧上升。**收获时相应取在膝点之前** |
| **代价** | 直接与**单位体积产量（titer）**冲突。需要做"每单位酸性峰的产量"这一目标函数，而不是单纯最大化 titer |
| **判读** | 若"产物 +42 化学计量"随诱导后时间**单调升高**，且与酸性峰% **同向** → 收获时相是可用的控制点。若两者不相关 → 说明本品乙酰化不主要由暴露时长决定，应转向 A2/宿主层面 |

> [!important] 与"包含体"工艺的相容性
> 包含体工艺的收获时相通常按"包含体累积量最大"来定。本报告建议改为双目标：**在保证可接受 titer 的前提下，选乙酰化尚未起飞的时间点**。这需要先有 A1 的时间-乙酰化曲线，不能凭经验拍。

### A2. 补糖 / 碳流策略——第二杠杆（直接对准"溢流"）

| 项 | 内容 |
|---|---|
| **文献依据** | ①葡萄糖时程中乙酰化与**葡萄糖消耗、乙酸外排同步**；②**ptsG 缺失使葡萄糖诱导的乙酰化完全消失** → 摄入速率是关键；③存在"加入窗口"（≤3 h 强、4 h 弱、5–6 h 无）；④**作者的核心论点即"碳流超过中央代谢能力（overflow）导致 AcP 依赖型乙酰化"** |
| **可操作形式** | ①**降低残余葡萄糖**：由脉冲式补糖改为**指数/DO-stat/恒低残余糖**补料，把残余葡萄糖控制在检出限附近（例如 < 0.5–1 g/L，具体以本品实测为准）；②**消除分批糖冲击**：避免初始高浓度葡萄糖一次性投入；③**降低比生长速率 μ**：用限速补料把 μ 控制在低于溢流阈值的水平；④**末期断碳/减碳**：进入稳定期后不再维持高碳供给 |
| **预期** | 碳流不再超过 TCA/氧化能力 → Pta 生成 AcP 的速率下降 → 胞内 AcP 下降 → 全局乙酰化下降 |
| **代价** | 降低 μ 可能降低体积产率与包含体形成速率；需重新平衡工艺时间 |
| **判读** | 若"残余葡萄糖曲线更平 / 乙酸峰值更低"的批次，其**产物 +42 与酸性峰% 同步更低** → 因果成立，可作为控制策略。**注意**：低乙酸本身不是充分证据（见上文 ΔackA 反例），必须与产物定点定量联动 |

### A3. 溶氧与营养平衡——针对"被忽视的溢流触发器"

| 项 | 内容 |
|---|---|
| **文献依据（外推）** | 本文定义溢流为"碳流**超过中央代谢途径的处理能力**"。在高密度发酵中，最先成为瓶颈的通常不是酶活而是**氧供给**——氧限制会把碳流推向发酵性代谢（乙酸生成），等价于人为制造溢流 |
| **可操作形式** | ①维持 DO 高于临界值（常见经验为 ≥ 30% 空气饱和度，以本品实测临界 DO 为准）；②**碳氮/碳磷平衡**：避免"碳过量 + 氮/磷限制"的组合；③避免富碳贫氧的补料脉冲 |
| **预期** | 减少发酵性溢流时段 → 减少 AcP 生成窗口 |
| **代价** | 提高通气/搅拌 → 剪切、泡沫、能耗；需评估对产物质量（如氧化）的影响 |
| **判读** | 在 DO 掉底的时间段与产物乙酰化是否相关；若相关 → DO 是控制点 |

### A4. 温度

| 项 | 内容 |
|---|---|
| **文献依据** | 本文全部实验在 **37 ℃**；温度本身不是本文的自变量。降低温度降低代谢速率与生长速率这一推论属**机制外推**，**不是本文结论** |
| **可操作形式** | 诱导后降温（例如 25–30 ℃，甚至更低），并**同时**降低补糖速率以匹配降低了的代谢能力 |
| **预期** | 代谢速率下降 → 单位时间碳流下降 → 溢流减少；附带收益是减缓脱酰胺/氧化等热驱动修饰 |
| **⚠️ 关键提醒** | **单独降温而不调补糖速率可能无效甚至有害**：碳供给不变而细胞处理能力下降，等于**人为加剧溢流**。温度与补糖必须**成对**调整 |
| **判读** | 若降温后乙酸峰值与产物 +42 同时下降 → 有效；若乙酸不变而 +42 不变 → 温度不是主要变量 |

### B 级：需验证的手段

**B1. 诱导强度与表达速率（IPTG 浓度、诱导 OD）**

- **与本文的关系**：本文的变量是碳流，不是表达强度。本项的机制假设是——**表达速率决定"产物作为乙酰化底物的供给速率"以及胞质暴露窗口**，属推论。
- **双向不确定性**：降低 IPTG → 代谢负担下降（可能减少溢流）**但也**延长了产物在胞质中的累积时间（可能增加暴露）。**两个效应方向相反，必须实测**。
- **可操作形式**：IPTG 浓度与诱导 OD 的 2×2 到 3×3 设计，读出"产物 +42 化学计量 / 每 mg 产物"。
- **附带收益**：若甲酰化（+28）或正亮氨酸误掺同时存在，降低表达速率对它们也是正向的（库内既往建议一致）。

**B2. 宿主背景：BL21 vs K-12 的"双因素"问题**

- 本品已确认存在 **+178 Da 葡萄糖酰化**（与 BL21 的 *pgl* 缺陷相关），这本身就是**宿主背景相关的酸性峰来源**。
- 而本文的 AcP 通路数据来自 **K-12**。若考虑更换宿主，**必须把两件事分开评估**：换宿主能解决 *pgl* 相关的 +178/+258；换宿主**是否**降低 AcP 依赖型 +42，**本文不能回答**，必须在新宿主上重做验证。
- **不建议**把"换宿主"作为降低乙酰化的首选方案——它是解决 +178 的方案，对 +42 只是"顺带可能"。

**B3. 培养基组成（碳源种类、氨基酸/富氮程度）**

- 本文的 TB7 是**富氨基酸缓冲培养基**，作者特别指出该体系中**葡萄糖消耗被推迟到稳定期**，这很可能是 TB7 特有现象——**说明培养基组成会改变"何时开始溢流"**。
- 本品若使用合成/半合成培养基，其"延迟耗糖"的现象与 TB7 未必相同。**不能照搬本文的时间点**（如"3 h 前加糖"），必须在本品培养基上重新测定溢流起始时刻。
- 可试的变量：葡萄糖 vs 甘油 vs 混合碳源；碳源投加总量；是否维持末期碳供给。

### C 级：菌株遗传改造（收益最高，监管成本最高，仅在前述无效时考虑）

| 改造 | 本文的直接依据 | 预期 | 重大风险 |
|---|---|---|---|
| **过表达 `ackA`**（增强 AcP→乙酸 排水） | ΔackA 使乙酰化**升高**（图 8A）→ 反向推论：提高 AckA 活性应降低 AcP 与乙酰化 | 降低 AcP 稳态浓度 → 降低全局乙酰化 | 增加乙酸生成（对 titer/质粒稳定性不利）；需实测净收益 |
| **减弱 `pta`**（减少 AcP 生成） | 缺乏 Pta 的突变株不表现葡萄糖诱导的乙酰化（引自 Weinert 2013 / Kuhn 2014） | 从源头减少 AcP | Δpta 影响乙酸同化；生长/产量风险 |
| **过表达 `cobB`**（NAD+ 依赖去乙酰化） | 本文明确：CobB **只能逆转一部分** AcP 敏感位点（仅 24 个位点同时受 AcP 与 CobB 调控） | 有限、位点选择性的降低 | **收益上限低**，不建议单独作为方案 |
| **缺失 `yfiQ`**（唯一已知 KAT） | 本文：YfiQ 依赖型乙酰化是**次要通路**，且其转录依赖 cAMP–CRP，在葡萄糖存在时被限制；其信号表现为高分子量条带，且在**葡萄糖耗尽后**最强 | 仅消除次要组分 | 收益有限；对 AcP 主通路无效 |
| **Δ`crp` / Δ`cya`** | 乙酰化**大幅丧失**（图 7A/B） | 理论上最有效 | ❌ **不可用于生产**：多效性调控、生长严重受损、碳源利用谱改变 |

> [!warning] 菌株改造与生物类似药的监管成本
> 对生物类似药而言，**更换/改造生产菌株属于重大变更**，将触发可比性研究（可能需要额外的表征 + 非临床桥接）。在**质量属性差值能够用工艺参数解释并控制**的前提下，**优先走 A 级工艺杠杆**；菌株改造只在 A/B 级已被证明无法达标时才启动，且必须与 RA/CMC 提前沟通。

## 实验设计、过程指标与判定标准

### 阶段 0：先把"要不要做"这件事判掉（1–2 周）

| 实验 | 目的 | 判读标准 |
|---|---|---|
| **0-1** 尿素-free vs 含尿素平行酶切，对酸性峰馏分做靶向 MS | 排除 +43 假象与 +42/+43 混算、抗体交叉富集 | 若 +43 只在含尿素路径出现 → 是**分析假象**，上游攻关方向应改为下游。若两条路径量相当 → 工艺真实修饰 |
| **0-2** 酸性峰/主峰/碱性峰 × 自研/原研 **四象限**靶向定量（分别报 +42 与 +43，不合并为"酰化总量"） | 建立"修饰量差 ↔ 酸性峰差"的对应 | 用 `1−exp(−Σpᵢ)` 做量级自洽性检查：若自研−原研的 +42 总化学计量能解释酸性峰差值 → **进入阶段 1**；若 <2% 且集中在单一位点 → **不进入**，转向其他成因 |
| **0-3** 确认 +42 的位点分布（MS/MS 定位：Lys ε-NH₂ vs N 端 α-NH₂） | 决定本文机制是否适用 | **多位点、低占位、Lys 为主** → 本文适用，进入阶段 1；**单一位点高比例、位于 N 端** → 本文杠杆无效 |

### 阶段 1：把本文的方法直接搬到发酵罐上（2–4 周）

**核心工具移植**：Schilling 用 **anti-acetyllysine Western blot** 做**时相读数**——这是本报告最省成本、最快见效的一条建议。

| 实验 | 操作 | 目的 |
|---|---|---|
| **1-1 发酵过程乙酰化时相曲线** | 在现有工艺下，按 1–2 h 间隔取样，做全菌裂解液的 **anti-AcK Western**，**同步记录**：OD、残余葡萄糖、乙酸、DO、诱导后时长、产物累积量 | 找出本品发酵的**乙酰化起飞点**，以及它与葡萄糖消耗/乙酸峰值的时间关系 |
| **1-2 胞内 AcP 测定** | 建立胞内 AcP 定量（酶法或 LC-MS），或至少建立趋势性读数 | 把"碳流"这一抽象概念变成可测的中间变量——**这是判定因果的关键中间指标** |
| **1-3 产物定点 +42 定量** | 对阶段 0 确定的位点建立 **PRM/MRM 靶向方法**，定量"每 mg 产物的 +42 化学计量" | 把"宿主乙酰化"与"产物乙酰化"分开——**本文测的是前者，本品的质量属性取决于后者** |

> [!tip] 1-1 的判读价值极高
> 若 anti-AcK 信号在某个时间点**急剧上升**，且该拐点与**乙酸外排开始**或**残余葡萄糖转升**重合 → 说明本品工艺**复现了本文的碳溢流机制**，A1/A2 杠杆值得投入。
> 若整条曲线**平缓无拐点** → 说明本品发酵未进入溢流状态，乙酰化可能来自其他环节（或该 +42 本身是分析假象），应回到阶段 0。

### 阶段 2：单因素筛选（3–6 周）

按 A1 → A2 → A3 → A4 顺序，每次只动一个变量，其余保持现状：

| 编号 | 变量 | 水平建议 | 主要读出 |
|---|---|---|---|
| S1 | 诱导后收获时长 | 4 / 6 / 8 / 10 / 12 h（或按产物量设点） | 产物 +42 化学计量/ mg；酸性峰%；titer |
| S2 | 补糖策略（残余葡萄糖目标） | 脉冲式（现状）vs 恒低残余糖 vs 指数补料 | 同上 + 乙酸峰值 + μ |
| S3 | 比生长速率 μ | 两到三个 μ 水平 | 同上 |
| S4 | DO 下限 | 例如 ≥20% / ≥30% / ≥40% | 同上 + 溢流时段占比 |
| S5 | 诱导后温度 | 现状 vs 降温（**同时调整补糖速率以匹配**） | 同上 |
| S6 | 碳源种类 | 葡萄糖 vs 甘油 vs 混合 | 同上 |

### 阶段 3：DoE 与工艺锁定（6–10 周）

- 把 S1–S6 中**证明有效**的 2–4 个因子纳入响应面设计（如 CCD 或 Box–Behnken）。
- **响应变量（多目标）**：①产物 **+42 化学计量 / mg 产物**（主）；②**IEC 酸性峰 %**（主，最终质量属性）；③titer / 体积产率（约束）；④其他关键质量属性（+178、+43、脱酰胺、二硫键图谱、DSC）——**必须同步监测，避免"按下葫芦浮起瓢"**。
- **锁定判据**：在 titer 可接受的可行域内，找到酸性峰% 最低且稳健（robust）的条件；并确认该更优条件在放大后仍成立。

### 过程分析与放行指标建议

| 层级 | 指标 | 建议频次 | 作用 |
|---|---|---|---|
| **输入端（可实时控制）** | 残余葡萄糖、比生长速率 μ、DO、温度、补料速率曲线 | 在线/高频 | 直接控制"碳流是否超能力" |
| **趋势性中间指标** | 发酵液乙酸浓度（外排速率） | 每 1–2 h | **溢流发生时段**的指示；**不可**单独作为 AcP 的替代指标 |
| **决定性中间指标** | 胞内 **AcP** 浓度 | 关键时间点（起飞前后） | 汇聚节点，因果链的核心 |
| **快速过程读数** | 全菌裂解液 **anti-AcK Western**（Schilling 原方法） | 时相曲线阶段高频，工艺锁定后抽检 | 最廉价的"乙酰化是否失控"预警 |
| **产物级决定性指标** | 产物**特定位点 +42 化学计量**（靶向 MS/PRM） | 每批 | 真正的质量属性读数，用于批间趋势与工艺变更评价 |
| **放行/相似性指标** | IEC 酸性峰%，以及酸性峰馏分的 +42/+43 归属 | 每批 | 最终判定 |

> [!note] 关于"残余糖"的一个实操细节
> 把残余葡萄糖压到极低会改变细胞的代谢状态（可能触发应激、改变产物形成速率）。**目标不是"糖越低越好"，而是"碳供给与细胞的氧化/同化能力匹配"**。判据应回到产物 +42 与酸性峰%，而不是残余糖这个代用指标的绝对值。

## 适用边界：上游能解决酸性峰的哪一部分

**必须先把"上游可解决的份额"算清楚**，否则会出现"优化了发酵但酸性峰没变"的挫败。

| 维度 | 本文条件 | 本品实际 | 外推风险 |
|---|---|---|---|
| 宿主 | K-12（BW25113 / AJW2179） | 自研疑为 BL21(DE3) 衍生（库内已检出 *pgl* 相关 +178 Da 葡萄糖酰化） | `pta`/`ackA`/`ptsG`/`crp` 通路在两菌中均存在，机制**预期保守**，但**通量水平不同**，需实测 |
| 产物 | 宿主自身蛋白（内源，胞质可溶） | 重组 Fc–TPO 肽融合蛋白，**以包含体形式沉积** | ⚠️ **最大的外推缺口** |
| 培养 | 分批、TB7（富氨基酸）+ 0.4% 葡萄糖、摇瓶、37 ℃ | 高密度补料发酵、合成/半合成培养基 | 溢流触发条件不同 |
| 观测 | 全局乙酰化 + 位点水平（label-free MS1 filtering） | 需针对产物特定位点的**靶向定量** | 方法可移植，靶点需自建 |
| 修饰类型 | 仅乙酰化（+42） | 酸性峰同时含 +42 与 +43 | 本文**不解释** +43 |

| 酸性峰成因 | 主要发生环节 | 上游（发酵）能否降低 | 依据 |
|---|---|---|---|
| **Lys 乙酰化（+42，AcP 依赖）** | **上游（胞内）** | ✅ **可以，且只能靠上游** | 本报告（Schilling 2015）；AcP 为胞内代谢物，下游无对应干预点 |
| N 端 Nα 乙酰化（+42） | 上游（共翻译，酶促） | ⚠️ 有限（受 N 端序列/宿主 Nα-乙酰转移酶水平影响） | 本文**不覆盖**；本品 N 端为 Met–Asp，可能性低 |
| **氨甲酰化（+43）** | **下游（碱性尿素复性）+ 分析前处理** | ❌ 基本不能；应通过下游尿素管理解决 | 见库内笔记《大肠杆菌Fc融合蛋白酰化修饰与酸性峰归属-文献检索与理论支撑》 |
| 葡萄糖酰化/磷酸葡萄糖酰化（+178/+258） | 上游（菌株 *pgl* + PPP 通量） | ⚠️ 只能通过宿主改造或 PPP 通量控制 | 库内既往结论（BL21 *pgl* 缺陷） |
| 二硫键错配 / 构象异构（Δm = 0） | **下游复性** | ❌ | 库内 DSC 证据指向此项 |
| 脱酰胺 / isoAsp（+0.98） | 上游 + 下游 + 储存（pH/温度/时间驱动） | ⚠️ 部分（降温、缩短时长有帮助） | 库内既往结论 |
| 糖化（+162） | 上游（补糖 + 时长） | ⚠️ 部分（与 A2 同向） | 库内既往结论 |

> [!warning] 不要把本报告当作"酸性峰的唯一解法"
> 自研原液酸性峰 ≈36.7% vs 原研 ≈10.3%，差值 ≈26 个百分点。**若阶段 0 的定量显示 +42 只能解释其中一小部分，那么即使上游乙酰化被降到零，酸性峰也不会达标。** 本报告解决的是"乙酰化这一块的份额"，其余份额必须并行推进（+43 的下游尿素管理、二硫键错配的复性优化、+178 的宿主策略）。

## 风险、反例与不可外推之处

| # | 风险 / 反例 | 说明 |
|---|---|---|
| 1 | **本文测的是宿主蛋白，不是重组产物** | 这是最根本的外推缺口。E. coli 有 4000+ 种蛋白在竞争 AcP；重组产物是被包进包含体的异源蛋白，其**可及性与暴露窗口完全不同**。"降低全局乙酰化 → 降低产物乙酰化"是**合理但未经证实的推论**，必须在本品上验证 |
| 2 | **乙酸低 ≠ AcP 低** | ΔackA 反例。把乙酸当作唯一控制指标会做出错误决策 |
| 3 | **降低碳流/μ 会降低 titer** | A1/A2 的收益以产量为代价。必须用"每单位酸性峰的产量"而非单纯 titer 做目标函数，并与 CMC/生产部门共同设定可接受边界 |
| 4 | **降温不配套调补糖 = 加剧溢流** | 见 A4。这是一个容易被误用的杠杆 |
| 5 | **本文无氨甲酰化数据** | 本文完全不能用于论证 +43 的来源或控制。切勿混用 |
| 6 | **培养基/时间点不可照搬** | 本文"3 h 前加糖才有效"是 TB7 缓冲富氨基酸培养基下的现象；本品培养基不同，必须重新测定溢流起始时刻 |
| 7 | **BL21 与 K-12 的通量差异未定** | 通路保守 ≠ 通量相同。若自研用 BL21，需在 BL21 背景上验证 ptsG/ackA/pta 的效应方向 |
| 8 | **"非酶促"不等于"无位点选择性"** | 位点特异性由微环境决定（Kuhn 2014）。降低 AcP 会按比例降低，**但不会清零**；不要把"目标 = +42 完全消失"设为验收标准 |
| 9 | **上游变更的监管成本** | 工艺参数调整相对可控；**菌株改造属重大变更**，需 RA 前置评估 |
| 10 | **多属性耦合** | 改变碳流/温度会同时影响 +178、+43、脱酰胺、二硫键图谱、DSC 与效价。**任何 A/B 级实验都必须同步测全套关键质量属性**，不能只看酸性峰 |
