CE-SDS 纯度检定中，同一批样品重复进样的峰面积波动是常见异常信号，可能源于进样环节的多个变量。本文从电动进样的定量模型出发，逐项分析气泡、样品离子强度、柱温与进样口凝胶缓冲液蒸发对峰面积和迁移时间的影响，最后给出系统化排查顺序与需要固定的条件。

## 问题现象：峰面积波动不是孤立事件

CE-SDS 做纯度检定时，峰面积在同一批样品的重复进样之间波动超过预期。这类波动并非总是随机出现——当峰面积下降与迁移时间漂移同时发生时，往往指向分离系统某个环节的持续变化。

一个典型案例：IgG Purity CGE 平台方法分析 IdeS 酶切 IgG 的 F(ab)₂ 片段时，F(ab)₂校正峰面积：7800 → 7300（均值7300，RSD 3.3%），总峰面积同步下降；迁移时间：23.6 min → 25.9 min（序列运行中持续增加）。该现象在两个实验室独立重现；已排除仪器硬件问题（电极、检测器、毛细管、光路、托瓶器）与上机前样品溶液不稳定性[依据 1]。这类「峰面积下降 + 迁移时间增加」的组合模式，是排查进样机制的重要线索。

## 定量基础：电动进样量由什么决定

电动进样（electrokinetic injection，EKI）的进样量由 Jorgenson 方程描述：

```
Q = π r² (μ_ep + μ_eof) E' t_inj
```

其中 μ_ep 为分析物电泳淌度，μ_eof 为电渗淌度，E' 为样品区带内的实际电场强度，t_inj 为进样时间。进样量取决于电泳淌度与电渗淌度之和、样品区带电场强度和进样时长[依据 2]。这意味着进样环节的任何变化——电渗流漂移、样品基质电导率变化或电流路径异常——都会直接表现为峰面积波动。

样品区带的实际电场强度由背景电解质（BGE）与样品基质的电导率之比决定：

```
E'_sample = E_applied × (κ_BGE / κ_sample)
```

当样品电导率高于 BGE 时，样品区带内电场被压缩（field de-amplification），进样量减少；样品电导率较低时则发生场放大（field amplification），进样量增加[依据 2]。因此，样品缓冲液与 BGE 的匹配程度是电动进样重现性的关键前提。

## 排查方向：气泡、离子强度与柱温

### 进样端毛细管口的气泡

动力学进样（电动进样）时，进样端毛细管口若存在气泡，气泡会截断电流，导致实际进样电场中断或减弱。实测表现为峰面积系统性偏低且 RSD 变大。检查重点包括进样针定位、样品管液面与密封状态。

### 样品缓冲液离子强度

由电导率比公式可知，样品缓冲液离子强度偏高时，κ_sample 升高，E'_sample 被压缩，进样量相应减少[依据 2]。实际工作中应固定样品缓冲液的配制（缓冲液种类、浓度、pH），并确保样品与 BGE 之间的电导率差保持在方法开发时确认的范围内。样品稀释或更换缓冲液批次后，应重新确认峰面积响应是否在可接受区间。

### 毛细管温度控制

柱温波动直接改变电渗流（μ_eof），进而影响进样量。进样前确认仪器恒温系统达到设定值、毛细管安装位置固定，是排除温度因素的基本操作。

## 最易忽视的机制：进样口凝胶缓冲液蒸发

### 峰面积下降与迁移时间漂移同源

当峰面积下降与迁移时间增加同时出现时，CE-SDS 文献将这一模式归因于进样口凝胶缓冲液小瓶的状态变化——蒸发、消耗与粘度漂移会改变进样口处 BGE 的电导率和粘度，进而改变电导率比与电动进样量[依据 3]。这是一条「行业已知问题」：SCIEX/MedImmune 技术报告指出，每次实验中进样口凝胶缓冲液小瓶都会发生蒸发；蒸发使凝胶浓缩、粘度升高，蛋白质迁移变慢，迁移时间逐渐增加，同时进样量减少导致峰面积下降[依据 1]。前述 F(ab)₂ 案例中迁移时间 23.6 → 25.9 min 的持续增加，与这一机制高度吻合。

### 凝胶缓冲液浓度与峰面积呈定量关系

Geurink 等（2021）在病毒疫苗蛋白 CE-SDS 方法开发中定量证明，凝胶缓冲液稀释会造成电动进样峰面积按比例降低[依据 3]。这说明进样口缓冲液状态不是次要因素，而是直接决定进样量的变量。

### 对策：矿物油覆盖

针对凝胶缓冲液蒸发，SCIEX/MedImmune 技术报告给出的解决方案是在进样口凝胶缓冲液小瓶液面上覆盖矿物油（mineral oil）层，有效防止蒸发，显著改善迁移时间稳定性[依据 1]。这是成本最低、文献支持最充分的干预措施。

## 系统化排查顺序与条件固定

结合上述机制，建议按以下顺序排查：

1. 进样口凝胶缓冲液状态：检查液面高度、有无浓缩或结晶；序列运行前后对比小瓶重量或液面变化；确认是否已加矿物油覆盖。
2. 进样端气泡：观察进样针定位、样品管液面与密封；核对进样时的电流曲线是否平稳。
3. 样品基质与 BGE 匹配度：核对样品缓冲液配制记录，确认离子强度是否符合方法规定。
4. 迁移时间变化模式：单向持续漂移优先指向凝胶缓冲液状态变化；随机波动则应检查温度控制与毛细管状态。

以下条件需要在方法中固定：每次进样前用运行缓冲液冲洗；样品盘温度设为固定值；进样口凝胶缓冲液小瓶覆盖矿物油层[依据 1]。

## 结论与适用边界

CE-SDS 电动进样峰面积重现性问题可以从电动进样公式出发系统排查：气泡截断电流导致峰面积系统性偏低且 RSD 变大；样品离子强度偏高压缩样品区带电场；柱温波动改变电渗流；而峰面积下降与迁移时间漂移并存时，应优先排查进样口凝胶缓冲液蒸发。矿物油覆盖有效防止蒸发，是文献支持最充分的低成本对策。

需要明确适用边界：电导率比相关的机制仅适用于电动进样；采用压力进样的 CE-SDS 方法不受样品/BGE 电导率比的影响，但气泡与温度控制问题仍需关注。文中案例数据来自 IgG Purity CGE 平台的 F(ab)₂ 分析，迁移时间和峰面积的具体数值不应直接外推到其他样品或方法。具体操作参数（如矿物油覆盖层厚度、小瓶更换频率）需结合所用平台与序列长度自行验证。
