本文整理一份覆盖早研至BLA全生命周期的结构表征分项策略，以质谱为核心技术平台，覆盖重组酶、糖蛋白激素、单抗与双抗等多产品类型及CHO、酵母、大肠杆菌三大表达系统。全文按策略定位、法规框架、表征矩阵、阶段执行、可比性研究、特殊分子类型、上市后监测与策略边界依次展开。

## 策略定位与技术平台

### 目的与适用范围

结构表征是生物制品质量研究的核心内容，贯穿产品全生命周期，是确立关键质量属性（Critical Quality Attributes, CQA）、支撑工艺理解和产品质量控制的科学基础。全面、准确的结构表征数据不仅是各阶段监管申报的必要组成部分，也为整个生命周期内产品质量一致性的维持和验证提供关键依据。

本策略旨在建立覆盖生物制品从早研（候选分子筛选期）、IND申报、临床期间变更管理、工艺性能确认（Process Performance Qualification, PPQ）至BLA申报全生命周期的结构表征研究规划体系。以质谱（Mass Spectrometry, MS）为核心技术平台，辅以多种互补分析技术，明确各阶段应执行的表征项目、分析深度和批次要求，确保结构表征数据的完整性、合规性和可追溯性，满足ICH Q6B及国内外各主要监管机构的技术要求。

本策略适用于以下类型重组生物制品的结构表征研究规划，涵盖原液（Drug Substance, DS）和制剂（Drug Product, DP）两个层面：

| 产品分类 | 代表产品 | 表达系统 | 关键结构特征 |
| ------ | --------------- | ------------------- | ---------------------------- |
| 酶类 | 重组透明质酸酶 | CHO | 高唾液酸化N-糖及O-糖（NANA/NGNA），PK相关 |
| 酶类 | 糜蛋白酶 | 酵母（Pichia pastoris） | 高甘露糖型N-糖，O-甘露糖基化，无唾液酸 |
| 酶类 | IgG降解酶（如IdeS） | 大肠杆菌（E. coli） | 无糖基化，特有PTM风险 |
| 酶抑制剂 | 重组乌司他丁 | CHO | O-糖（硫酸软骨素GAG链）+ N-糖，结构复杂 |
| 糖蛋白激素 | FSH-CTP（长效促卵泡素） | CHO | 多位点N-糖/O-糖，CTP区域O-糖，高唾液酸化 |
| 糖蛋白激素 | 重组绒促性激素（hCG） | CHO | α/β异二聚体，β亚基CTP区域O-糖 |
| 糖蛋白激素 | 重组促红细胞生成素（EPO） | CHO | 3×N-糖位点+1×O-糖位点，高唾液酸化 |
| 单克隆抗体 | 单抗（皮下注射，SC） | CHO | IgG1 Fc N-糖（Asn297），高浓度制剂 |
| 双特异性抗体 | 双特异性抗体 | CHO | 双臂结构，异源二聚体，链配对验证 |

### 核心原则

- **以质谱为核心，多技术互补**：以质谱为核心结构表征技术平台（完整分子量、还原/脱糖质谱、肽图LC-MS/MS、糖型分析、PTM分析），辅以CD、DSC、SEC-MALS、IEX、CE-SDS、cIEF/iCIEF等互补技术，构建多维度、交叉验证的表征体系，各技术方法相互印证，确保表征结论的可靠性。
- **递进式研究深度**：不同注册阶段采用差异化的研究深度和批次要求，随申报阶段推进逐步加深至全面精细表征，确保资源投入与阶段性监管需求相匹配。
- **可比性研究贯穿全程**：工艺变更时以结构表征可比性数据为核心证据，按ICH Q5E原则系统评估变更前后产品结构相似性，确保临床与商业批次结构一致性。
- **基于风险动态调整**：根据分子类型（糖蛋白激素复杂性 vs 无糖基化蛋白）、表达系统特点（E. coli特有PTM风险、CHO唾液酸化、酵母高甘露糖）、给药途径（SC注射高浓度聚集风险）等因素，动态调整表征范围和深度。
- **合规优先，引用真实**：所有表征项目设计依据经确认的现行法规，所有引用来源均经核实，确保申报数据满足目标市场（中国、美国、欧盟、日本）监管要求。

### 技术平台概览

| 技术平台 | 分析对象 | 主要信息输出 |
| --------------------------------- | -------- | ------------------------ |
| Intact MS（完整质谱） | 完整蛋白分子 | 完整分子量（含糖），异质性评估 |
| Reduced MS（还原质谱） | 还原后各亚基/链 | 各链分子量，链配对确认 |
| Deglycosylated MS（脱糖质谱） | 脱糖后蛋白骨架 | 蛋白骨架精确分子量，无糖蛋白序列质量 |
| 肽图LC-MS/MS（Peptide mapping） | 酶解肽段 | 序列覆盖率（>95%），PTM位点与程度 |
| N-糖链图谱（Released N-glycan） | 释放N-糖链 | N-糖型类别与相对比例（%） |
| O-糖链图谱（Released O-glycan） | 释放O-糖链 | O-糖型类别与相对比例（%） |
| 糖肽LC-MS/MS（Glycopeptide analysis） | 含糖位点的肽段 | 位点特异性糖型分布，位点占用率 |
| 唾液酸定量（DMB-HPLC/MS） | 水解释放唾液酸 | NANA和NGNA含量（mol/mol蛋白） |
| 圆二色光谱（CD） | 二级/三级结构 | α-螺旋/β-折叠比例，远UV/近UV CD谱 |
| 差示扫描量热法（DSC） | 热解折叠 | 熔融温度（Tm），焓变（ΔH），热稳定性 |
| SEC-MALS | 聚集体/片段 | 绝对分子量（Mw/Mn），dn/dc，聚集体比例 |
| CE-SDS（还原/非还原） | 分子大小完整性 | 主峰%，片段%，聚合物% |
| AUC-SV（沉降速度） | 分子大小分布 | 沉降系数（s），水动力半径，聚集体 |
| IEX（CEX/AEX） | 电荷变异体 | 电荷变体分布，各峰面积%，MS辅助鉴定 |
| cIEF/iCIEF | 等电点 | pI值，等电点异质性分布 |

## 结构表征项目总览矩阵

矩阵为结构表征工作的核心规划工具，按注册阶段（列）和表征类别（行）双维度呈现全部表征项目的执行要求。

**符号约定：**

| 符号 | 含义 |
|------|------|
| ● | 必须执行——该阶段法规明确要求或行业标准强烈建议的表征项目 |
| ○ | 建议执行——根据产品特性和风险评估建议纳入，可结合实际情况调整 |
| — | 通常不适用——该阶段通常无法规要求，如产品存在特殊风险可另行评估 |

矩阵中各表征项目默认适用于全部产品类型，带上标数字的项目参照表格下方脚注了解适用产品范围限制。阶段列定义：**IND**为IND申报阶段，毒理批次+GMP批次，建立基准表征数据包；**临床**为临床期间，以代表性批次监测和变更桥接为主；**PPQ**为工艺性能确认阶段，商业化规模≥3批，为BLA提供主要数据；**BLA**为BLA申报阶段，完整表征数据包汇总。

## 各注册阶段表征策略

### 早研阶段（候选分子筛选期）

本阶段以速度和通量为优先，不要求完整的法规级表征，在候选分子选择阶段快速确认分子身份、初步评估物化特性，支持候选分子筛选和前导分子确认。批次为研发批次（非GMP），通常为小规模（<10 mg）。

主要表征内容：

- 完整质谱（Intact MS）：确认分子量，初步评估糖基化异质性
- SEC（纯度）：评估主峰纯度和聚集体风险
- SDS-PAGE/CE-SDS：确认链结构完整性
- 初步N-糖型谱：对糖蛋白激素/Fc融合蛋白了解糖基化概况
- 生物活性快速评估（与结构表征互补）

### IND申报阶段

本阶段目标为建立产品结构表征的基准数据包（Baseline Characterization Package），支持IND申报，并为后续可比性研究提供参考数据，确立CQA初步清单。

| 批次类型 | 数量要求 | 规模要求 | 说明 |
|---------|---------|---------|------|
| 毒理批次 | ≥1批 | 实验室至中试规模 | 支持毒理学研究，可与GMP批次同批或不同批 |
| GMP批次 | ≥1批 | 中试规模 | 用于IND申报，也可支持I期临床样品供应 |

表征深度执行矩阵中IND列所有●项，推荐同时执行○项以建立更完整的基础数据。核心表征内容基于ICH Q6B要求：一级结构（完整分子量、肽图序列覆盖率≥95%、N/C末端序列、氨基酸组成）、PTM分析（肽图LC-MS/MS鉴定主要修饰类型和位点）、糖基化（N-糖位点鉴定、N-糖型谱，适用产品进行O-糖和唾液酸分析）、二硫键与游离巯基、物理性质（消光系数、pI）、高级结构（远紫外CD、DSC）及分子异质性（SEC-MALS、CE-SDS、IEX、cIEF）。

IND阶段表征数据包要求（参照ICH Q6B及NMPA CDE《治疗用重组蛋白药物首次申报临床试验药学资料撰写指导原则》[2026]）：

- 完整一级结构表征数据（包括序列确认、PTM分析）
- 主要糖基化特征描述（适用产品）
- 理化性质（分子量、pI、EC）
- 高级结构初步表征（CD、DSC）
- 纯度和杂质分析（大小变异体、电荷变异体）
- 生物活性测定（功能学表征，非本策略重点）

申报资料位置：CTD 3.2.S.3.1（原液特性鉴定）/ 3.2.P.2（制剂开发）。

### 临床期间

在临床试验期间维持结构一致性监控，当发生工艺变更时执行可比性研究，积累支持BLA申报的长期结构稳定性数据。无工艺变更时，每批临床批次执行常规检验项目（SEC-MALS、IEX、CE-SDS），代表性批次（每临床阶段至少1批）执行全面结构表征中的核心项目（完整质谱、糖型、CD/DSC），无需对每批临床样品进行全面结构表征。发生工艺变更时按可比性研究策略执行，变更规模越大，可比性表征的范围和深度越高。

### PPQ工艺验证阶段

在商业化生产规模下确认工艺可重复性，同步完成商业化批次的全面结构表征，为BLA申报提供主要结构表征数据。

| 批次要求 | 说明 |
|---------|------|
| 批次数 | ≥3批次 |
| 规模 | 商业化规模（最终放大规模） |
| 包装 | 拟上市包装 |
| 工艺 | 经验证的最终商业化工艺 |

表征深度执行矩阵PPQ列所有●项及关键○项，三批之间数据具有批间一致性分析意义，建立批间变异范围。关键输出为商业化批次结构基准数据、批间一致性评估（三批间结构属性的统计分析）及关键质量属性（CQA）的商业化批次范围确认。

### BLA申报阶段

提供完整的结构表征数据包，以ICH Q6B要求为基准，满足目标申报市场（中国、美国、欧盟、日本）的监管要求，支持上市注册批准。批次来源以PPQ工艺验证批次为主，必要时补充额外特征研究批次（如HDX-MS研究）。

| 类别 | 内容要求 |
|------|---------|
| 一级结构 | 完整序列确认（≥3批），4种质量状态、肽图（序列覆盖率）、N/C末端、氨基酸组成 |
| PTM全谱 | 主要PTM类型鉴定和定量（基于表达系统特有风险，见附录A） |
| 糖基化 | N-糖型谱（≥3批批间一致性）、O-糖（适用）、唾液酸定量（适用）、位点特异性糖型 |
| 二硫键 | 二硫键全图谱，游离巯基定量 |
| 高级结构 | CD（二级结构），DSC（Tm，≥3批），荧光（三级结构），HDX-MS（建议，高风险产品） |
| 分子异质性 | SEC-MALS（聚集体历史趋势），CE-SDS，AUC，IEX（+MS鉴定各峰），cIEF |
| 物理性质 | EC，pI，Rh |

申报资料格式对应CTD 3.2.S.3.1（原液）和3.2.P.2（制剂）的结构表征综合报告，按目标市场格式要求组织。

### 理化对照品表征与新旧批次桥接

适用于任何注册阶段内发生的理化参考标准品（Reference Standard, RS）批次更换情形，包括早期研究批次用尽、更换至更高规模生产批次、对照品效期到期后的更新。新制备对照品须完成与BLA阶段等效深度的全面结构表征，包括第三章矩阵中BLA列所有●项，以及附录A所列关键PTM的分析。

| 比对维度 | 分析项目 | 比对方式 |
|---------|---------|---------|
| 一级结构 | 完整/还原/脱糖分子量，肽图 | 完全一致性（质量偏差<5 ppm） |
| PTM | 主要修饰类型和相对比例 | 定量比对，建立允许范围 |
| 糖基化 | N-糖型分布，主要糖型比例 | 统计学比对，主峰±5%接受标准 |
| 唾液酸 | NANA/NGNA定量 | mol/mol定量比对 |
| 高级结构 | CD谱形、DSC Tm | 波谱比对，Tm差值≤1°C |
| 分子异质性 | SEC-MALS主峰%，IEX分布图 | 数值比对，在历史批次范围内 |

等效性判断原则：新旧对照品关键结构属性应高度相似，任何显著差异须有科学解释，证明差异不影响对照品在检验中的功能等效性。

## 可比性研究策略

可比性研究在发生制造工艺变更时，用于评估变更前后产品结构和质量属性的相似性，以证明变更不影响产品的安全性、有效性和质量。

| 变更类型 | 风险级别 | 触发可比性研究要求 |
|---------|---------|----------------|
| 宿主细胞系/种子批/细胞库 | 高风险 | 全面结构可比性（矩阵所有●项） |
| 生产规模放大（如中试→商业化） | 高风险 | 全面结构可比性 |
| 生产场地变更 | 高风险 | 全面结构可比性 |
| 培养基/主要原材料变更 | 中-高风险 | 侧重糖基化、PTM的表征 |
| 下游纯化工艺步骤变更 | 中风险 | 重点关注杂质谱和关键质量属性 |
| 制剂处方变更 | 中风险 | 重点关注聚集体、电荷变体、HOS |
| 分析方法变更（用于结构表征） | 低-中风险 | 方法桥接，结构可比性证据 |
| 包装材料变更 | 低风险 | 稳定性关注为主，结构表征选择性 |

### 研究设计原则（基于ICH Q5E）

- **平行对照**：变更前样品（Pre-change, PC）与变更后样品（Post-change, PC）在相同条件下同批检测
- **多批次**：各取≥3批（IND阶段可为≥1批变更前 + ≥2批变更后），BLA阶段要求≥3批对3批
- **代表性批次**：选择各方面均具代表性的批次，避免选择性偏差
- **方法适用性**：所有可比性分析方法须经验证，方法适用于检测相关变更可能引入的差异

### 可比性表征项目与深度

核心表征项目每次可比性研究均需执行：一级结构（完整质谱、肽图、主要PTM定量）、糖基化（N-糖型谱，适用产品含O-糖、唾液酸）、大小变异体（SEC-MALS、CE-SDS）、电荷变异体（IEX + cIEF）、高级结构（CD + DSC）。

扩展表征项目根据变更风险评估选择：位点特异性糖型（糖肽分析）、单个PTM精细定量、AUC（大分子量变体评估）、HDX-MS（高级结构精细比对）、IEX峰切割+MS鉴定（电荷变体来源分析）。

### 相似性评估方法

| 评估方式 | 适用场景 | 判断依据 |
|---------|---------|---------|
| 逐项定性比对 | 二级/三级结构谱图 | 谱图形状、峰位置一致 |
| 定量比对（均值±范围） | 糖型比例、PTM水平 | 变更后在变更前历史批次范围内 |
| 统计学方法（等效性检验） | 积累足够批次数后 | 以90%置信区间在等效边界内为判据 |
| "质量范围"方法（Quality Range） | BLA可比性评估 | 参照美国FDA生物类似药指导原则（2025年9月版）的逐步评估框架 |

### 可比性研究批次要求

| 阶段 | 变更前批次 | 变更后批次 | 特殊要求 |
|------|---------|---------|------|
| IND阶段 | ≥1批（最近生产批次） | ≥1批（代表性批次） | 至少含1批GMP批次 |
| 临床期间 | ≥1批（关键临床批次） | ≥2批 | 尽量包含临床批次 |
| BLA阶段 | ≥3批（代表性历史批次）| ≥3批（PPQ批次）| 必须包含商业化批次 |

## 特殊分子类型表征策略

### 复杂糖蛋白激素（EPO / FSH-CTP / hCG）

以上产品均为CHO表达的高度糖基化蛋白，糖基化对其PK（半衰期）和PD（活性）具有关键影响；FSH-CTP和hCG为α/β异二聚体结构，每个亚基携带独立的糖基化位点。

糖基化表征重点：

- **N-糖**：EPO含3个N-糖位点（Asn24、Asn38、Asn83），FSH含2个（α亚基Asn52/Asn78，β亚基Asn7），hCG含2个（α亚基Asn52/Asn78）；需进行位点特异性N-糖型分析
- **O-糖**：EPO含1个O-糖位点（Ser126）；FSH-CTP的CTP区域含4个O-糖位点；hCG β亚基CTP含4个O-糖位点；O-糖分析须单独优化（不同于N-糖分析条件）
- **唾液酸化**：高唾液酸化程度与体内半衰期正相关，须定量NANA和NGNA含量；NGNA（非人型唾液酸）有潜在免疫原性风险，需定量控制

异二聚体表征：α/β亚基的还原质谱确认各亚基分子量；非还原条件下评估二聚体组装效率；FSH-CTP的CTP融合延伸使β亚基质量显著增加，须充分考虑胰酶消化前的糖链脱除优化。

法规关注点：参照ICH Q6B和EMA/CHMP/BWP/532517/2008 Rev. 1；中国申报参照《人用单克隆抗体质量控制技术指导原则》框架精神，并关注中国药典（CP 2025年版三部）中EPO等产品的质量标准。

### 含硫酸软骨素O-糖修饰的分子（重组乌司他丁）

重组乌司他丁（Ulinastatin，UTI）为含两个Kunitz型丝氨酸蛋白酶抑制结构域的蛋白，含N-糖和独特的O-连接硫酸软骨素（Chondroitin Sulfate, CS）糖胺聚糖（GAG）链，GAG链的硫酸化程度和链长均具有异质性，分子量远高于蛋白骨架。

表征挑战与策略：

- **蛋白骨架与糖链分步分析**：先用ChABC（软骨素酶ABC）消化去除CS链后分析蛋白骨架（肽图，PTM），再单独分析释放的CS/GAG链
- **GAG链分析**：采用HILIC-MS或CE-MS分析GAG链长度分布和硫酸化模式；高分辨MS（FTICR或Orbitrap）是首选
- **唾液酸化**：乌司他丁的N-糖亦具有唾液酸化，需单独定量
- **完整分子量**：因GAG链高度异质性，Intact MS信号宽泛（MW分布宽达数万Da），通常以还原质谱和脱糖/脱GAG后质谱为主要表征手段

法规参考：目前尚无专门针对CS-GAG修饰蛋白的ICH专项指南，须参照ICH Q6B一般原则，并充分发挥科学理解和风险基础的判断。

### 高唾液酸化酶类（重组透明质酸酶）

重组人透明质酸酶PH20（rHuPH20）为CHO表达的单链糖蛋白，含多个N-糖和O-糖位点，唾液酸化程度（特别是α2-6链接的NANA）对其半衰期和皮下给药时的扩散增强效应具有重要影响。

唾液酸化表征重点：

- **NANA vs NGNA区分**：CHO细胞在含牛血清培养基中可从外源Neu5Gc合成少量NGNA，需通过DMB-HPLC-MS精确区分并定量；NGNA有免疫原性风险，须建立控制标准
- **N/O糖链分布**：精细分析各唾液酸化糖型的比例（单唾液酸化、双唾液酸化、多唾液酸化糖型）
- **唾液酸含量与酶活相关性**：建立批次唾液酸化程度与酶催化活性的相关性，支持CQA决策

皮下给药特殊考量：作为SC注射助推剂（hyaluronidase facilitator），透明质酸酶的结构完整性和酶活性直接影响皮下给药系统的性能，需评估高浓度制剂条件下的聚集风险。

### 大肠杆菌表达重组蛋白（IgG降解酶）

大肠杆菌（E. coli）表达系统无N-糖基化能力，IgG降解酶产品不含糖基化修饰，但因包含体复性工艺（常用尿素或盐酸胍变性再复性）而具有哺乳动物系统所没有的特有PTM风险。

E. coli特有PTM风险（需在IND阶段全面评估，参见附录A）：

- **氨甲酰化（Carbamylation）**：尿素在室温分解产生氰酸盐，与蛋白Lys ε-氨基和N端α-氨基反应（+43 Da）；此修饰为E. coli包含体工艺高度特有，需通过肽图LC-MS确认并控制
- **葡萄糖酸酰化（Gluconoylation）**：His-tag蛋白N端可被6-磷酸葡萄糖酸内酯修饰（+178 Da），导致N端异质性；磷酸葡萄糖酸酰化（+258 Da）亦可发生
- **N端fMet保留**：高表达时MAP酶饱和，N端Met切除不完全，产生分子量异质性
- **二硫键错配**：复性过程中可能发生错误二硫键配对，需通过非还原肽图确认

HOS表征重点：由于无糖基化，HOS表征（CD、DSC、荧光）是评估蛋白正确折叠的核心工具；须重点确认与天然来源IgG降解酶的结构等效性。

工艺控制建议：尿素溶液须新鲜配制（<4 h），4°C储存；优化PDF/MAP酶辅因子（Co²⁺/Mn²⁺），降低N端异质性；发酵过程控制葡萄糖浓度，减少糖化。

### 酵母表达蛋白（糜蛋白酶）

毕赤酵母（Pichia pastoris）等酵母系统可进行N-糖基化，但糖型为高甘露糖型（Man5-Man>50），且可发生O-甘露糖基化，与CHO细胞的复合型N-糖和哺乳动物O-糖有本质区别。

酵母特有表征考量：

- **高甘露糖N-糖型**：Man5为基础，酵母可进一步延伸产生极高甘露糖（>30 Man残基，称为超甘露糖化/Hypermannosylation），导致分子量和大小的高度异质性；须控制培养条件（pH、温度）抑制超甘露糖化
- **O-甘露糖基化**：酵母PMT（甘露糖转移酶）介导Ser/Thr的O-甘露糖基化（每个位点+162 Da），可在多个位点多次修饰；与哺乳动物黏蛋白型O-糖不同
- **无唾液酸化**：酵母无唾液酸化能力，与CHO产品有本质区别；无NGNA风险
- **检测策略**：Intact MS因高度异质性信号分散，应以PNGase F脱糖后的Intact MS和肽图LC-MS/MS为主要表征手段

### 双特异性抗体

双特异性抗体（BsAb）同时包含两个不同的抗原结合域，其结构复杂性远高于常规mAb。常见格式包括非对称IgG（如KIH, CrossMab）、串联ScFv、DART等。

特有表征挑战：

- **链配对验证（Chain Pairing）**：对于非对称IgG格式，须确认正确的HC/LC配对（异源二聚体形成），排除同源二聚体（homodimer）杂质；推荐使用Native MS（非变性质谱）分析完整抗体的亚基组成
- **异源二聚体纯度**：通过非变性SEC-MS或离子交换色谱评估异源二聚体比例，须建立明确的接受标准
- **两臂独立表征**：对两个抗原结合域分别进行结构表征（如抗原A结合域 vs 抗原B结合域），可通过选择性酶切（如IdeS消化分离Fab和Fc）后分析
- **糖基化**：若含Fc区，Asn297 N-糖表征与常规mAb相同；若双臂格式有额外Fc区，需分别评估

法规参考：参照《双特异性抗体抗肿瘤药物临床研发技术指导原则》（NMPA CDE, 2022年第40号）及ICH Q6B中对融合蛋白的适用性原则。

### 皮下注射单抗/双抗产品

皮下注射（SC）制剂通常需要高浓度配方（50-200 mg/mL），高浓度环境下蛋白质-蛋白质相互作用增强，聚集风险显著高于静脉注射制剂。

结构表征特殊考量：

- **高浓度聚集体**：在拟用SC浓度下评估聚集体，SEC-MALS须使用代表制剂浓度的样品；动态光散射（DLS）实时监测高浓度下的流体力学半径变化
- **粘度**：高浓度SC产品粘度是注射可行性关键参数，结构表征应提供蛋白浓度-粘度关系数据
- **可提取体积**：SC给药通常体积≤1.5 mL，高浓度制剂的分子完整性须在相应条件下验证
- **自聚集倾向（Self-association）**：相互作用色谱（HIC）结合自相互作用纳米颗粒光谱（SINS）评估分子自聚集风险

## 上市后监测、项目管控与策略边界

### 上市后结构监测

上市后监测的目标包括：监测商业化生产批次结构属性的持续稳定性和批间一致性；及时发现工艺漂移（Process Drift）或原材料变化对结构的潜在影响；支持年度产品回顾（APR）和再注册（如适用）；为上市后变更管理（PACMP）提供结构基础数据。

| 监测类型 | 频率 | 批次选择 | 监测项目范围 |
|---------|------|---------|------------|
| 年度结构快检 | 每年≥1批/规格 | 商业化生产批次 | 完整质谱、N-糖型、SEC-MALS、IEX、CD；缩减版（不需全项） |
| 定期完整表征 | 每3年≥1批或发生变更时 | 代表性商业批次 | 矩阵BLA列所有●项 |
| 变更后全面表征 | 变更实施后首批 | 变更后生产批次 | 按可比性研究策略执行 |

触发全面结构表征的条件：年度快检发现结构属性超出历史批次范围（OOT/OOS）；原材料（培养基、层析介质等）供应商或规格变更；生产工艺参数的意外偏差；来自市场不良事件的安全性信号（提示潜在结构相关问题）；法规机构要求的周期性重新确认。

### 项目管理与责任分工

跨部门协作分工：质量控制（QC）负责实验方案起草、样品分析、数据记录与OOS调查；质量保证（QA）负责方案审核、数据完整性审查、偏差管理与变更控制；生产部门提供表征批次样品并通知工艺变更；研发/CMC负责整体策略设计、技术指导与申报资料撰写（CTD 3.2.S.3.1/3.2.P.2章节）；注册（RA）负责法规符合性审核与目标市场申报资料递交。

关键里程碑：IND申报前（≥3个月）完成IND阶段全部●项表征（至少1批GMP批次）；PPQ完成后（BLA申报前≥6个月）完成3批PPQ批次全面结构表征与批间一致性分析；BLA申报时整合所有阶段结构表征数据；获批后按年度监测计划执行，发现偏差及时响应。

### 策略适用边界与待注意问题

本策略的适用边界由产品类型与法规状态共同界定。产品覆盖重组酶、酶抑制剂、糖蛋白激素、单抗与双抗，表达系统涵盖CHO、酵母与E. coli，但策略框架基于ICH Q6B体系，中国申报时须注意ICH Q6B尚未被NMPA正式采纳实施，应以国内指导原则为优先准据。

方法学上存在若干已知限制：乌司他丁的CS-GAG修饰目前无专项ICH指南，依赖科学判断与一般原则；高糖基化分子的Intact MS信号因异质性而宽泛（GAG链分布宽达数万Da），需以还原质谱和脱糖/脱GAG后质谱为主要手段；酵母产品的高甘露糖化使Intact MS信号分散，应以PNGase F脱糖后分析为准。这些边界决定了矩阵中"通常不适用"项的实际处理方法。
