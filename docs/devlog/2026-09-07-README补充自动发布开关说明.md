## 实现

**两层开关分开讲，不是一句话带过。** 「定时任务要不要跑」和「跑出来的
候选要不要直接发布」是两件事，容易被读者当成一个开关——不拆开讲，
「关闭自动发布」这句话本身就有歧义（关的是哪一层）。这也是这次要写文档
的直接原因：用户已经用过一轮「关闭自动发布」的功能，还是要追问「怎么
开关」，说明现有措辞没把这两层说清楚。

**给出具体要改的代码行，而不是只说「去改 workflow」。** 如果真要恢复
「定时任务校验过就直接发布」这条旧行为，应该能照着文档直接动手，不需要
翻两篇 devlog 去确认当年改的是哪一行；但同时明确写「不建议」并链到两次
实测事故，不鼓励顺手就改。

**放在「手动触发一次发布」之前而不是之后。** 「手动触发一次发布」讲的是
单次操作（这次要不要发），这一节讲的是全局默认（以后每次自动跑要不要
发）——量级不一样，先讲全局开关，再讲单次的手动操作，读者不会把两者
混着理解成同一件事。
