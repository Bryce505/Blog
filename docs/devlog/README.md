# 开发日志

一次改动一个文件，文件名 `YYYY-MM-DD-<短标题>.md`，按文件名排序即时间顺序。
规矩写在仓库根目录的 [`CLAUDE.md`](../../CLAUDE.md)。

## 模板

```markdown
# YYYY-MM-DD　<一句话说清这次做了什么>

## 背景

为什么要改。写实测现象：什么坏了、坏成什么样、影响多大。

## 变更

- 新增：……
- 修改：……
- 删除：……

## 实现

关键做法与取舍。为什么选这个方案，放弃了什么方案，放弃的理由。

## 动了哪些文件

| 文件 | 动作 | 说明 |
|---|---|---|
| `pipeline/xxx.py` | 新增 | …… |

## 验证

自检项数、实测数据、浏览器验证结果。
```
